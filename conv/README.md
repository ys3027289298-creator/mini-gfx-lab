# conv

长冲激响应直接卷积太慢时使用分块频域卷积。

`conv_run` 一次性完成长度为 `N` 的输入与长度为 `M` 的冲激响应的线性卷积，
`conv_create` / `conv_process_block` 提供流式接口。采用均匀分块重叠保存：
冲激响应按块长切成若干段，每段只在创建时做一次 FFT；每处理一个输入块只做
一次正变换、一次逆变换，以及每段一次长度为 FFT 长度的复数乘加。输出取逆
变换结果的后半段，长度为 `2 * block_len` 的帧保证该段没有循环卷绕。

- 支持任意正整数块长；FFT 长度取 `>= 2 * block_len` 的最小 2 的幂。
- 全部使用双精度，与直接卷积逐样本误差在 `1e-9` 内（自检实测约 `1e-12`）。
- 块长 1024、输入 32768 点、冲激响应 16384 点时，比直接卷积快约 50 倍；
  自检中对这个倍数设了下限。
- 内存为 `O(M + block_len)`，与输入总长度无关：两块 FFT 大小的缓冲、
  一块块长历史，加上滤波器频谱和输入频谱延迟线各 `O(M)`。
- 流式接口 `conv_process_block` 不做分配；`conv_run` 每次调用只做
  固定次数的分配。
