# quest

数据驱动的任务/成就系统，替代写死在代码里的条件判断。

- **条件树可配置**：文本配置定义 `counter` / `flag` / `cond`（`and`/`or`/`not`/阈值叶子）/ `quest`，加载即生效，支持前向引用。
- **进度可累加与回滚**：`quest_add` 记日志累加（负增量可直接回退），`quest_undo` 逐条撤销，`quest_commit` 设提交点。回滚只覆盖计数器，flag 是即时状态。
- **完成锁存**：任务完成后不可撤销、不重复触发，`on_complete` 回调保证只调一次。
- **配置校验**：加载时检出条件树成环（三色 DFS）、缺失引用、未知计数器、重名，错误可通过 `quest_error` 逐条读取。
- **一致性**：自检用 4000 步随机操作（加/减/撤销/提交）与逐条手工判定对拍，完成状态与触发次数必须完全一致。
- **性能**：自检末尾对 1000 条任务做全量求值计时，输出 `bench_full_pass_us`（全部条件同时达标、单遍完成 1000 条的满负荷耗时）与 `bench_warm_pass_us`（全部锁存后的稳态耗时）。

`make test` 跑自检。
