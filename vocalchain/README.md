# vocalchain

人声处理链：降噪（向下扩展）→ 自动增益 → 限幅，三段可任意换序、可单独旁路。

```bash
make test
```

- **与手工串联一致**：`manual_run` 用同样三个 stage 函数按目标顺序直写，链式路径的输出与之逐采样相同；自检对全部 6 种顺序都做比对（`all_orders_match_manual`，maxdiff=0）。
- **顺序可配**：`chain_set_order` 接受任意排列，在块边界生效；重复项和非法 id 会被拒绝且不改动链；换序不重置任何 stage 状态，旁路渐变的位置跟着 stage 走。
- **换序电平差量化**：自检枚举全部 6 种顺序，打印 RMS、峰值、停顿段底噪以及相对 `g-a-l` 的差值（dB）。本信号上总电平差 0.79 dB；更明显的是停顿段底噪——AGC 放在门限之前会把噪声抬过阈值，停顿段从 −53.1 dB 变成 −37.9 dB（差 15.1 dB）。
- **旁路无爆音**：旁路是干湿交叉渐变（10 ms 斜坡），旁路期间 stage 仍持续处理，所以重新启用后输出与从未旁路过逐采样一致；自检同时跑一个硬切换对照组，硬切换的跳变比渐变路径高一个数量级（例如限幅器 0.73 对 0.062）。
- **限幅位置**：只有限幅器在末级时峰值才保证 ≤ −1 dBFS，其它顺序不保证（自检只对末级顺序断言峰值上限）。
