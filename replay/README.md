# replay

确定性输入录制、按序回放与逐帧状态比对，用于定位战斗回放与原始记录不一致的首个分歧。

```bash
make test
```

- 日志是定长记录流：24 字节头 + 每帧 12 字节输入，可选 40 字节状态快照。
  体积 `24 + 52 * 帧数`（带快照）或 `24 + 12 * 帧数`（仅输入），随时长严格线性。
- 模拟器只用 Q16.16 定点数，回放逐位可复现；回放读完输入即模拟，再与当帧快照
  逐字段比对。
- 首个分歧输出帧号与字段名（`frame/x/y/vx/vy/hp/rng/combo/score`），并给出
  记录值与重放值；同时校验输入帧号是否按序。
- 自检覆盖：全帧一致率 100%、输入篡改与快照篡改定位到准确帧/字段、多处篡改只报
  最早一处、截断日志被拒绝、日志体积逐帧定长且随帧数线性增长。
