# haptics

低频驱动震动强度标定：能量→幅度幂律拟合（含 95% 置信区间）、该幂次下幅度序列的抖动上界曲线、生成参数校验。

```bash
make test
```

输出：幂次与置信区间、生成参数、抖动上界曲线、参考/生成序列与偏差表、抖动越界时段报告。

判定规则：生成所用幂次必须落在置信区间内，出区间仍使用按不通过；抖动越界会打印具体时段（`jitter_violation segment t=[...] frames=[...]`）。生成序列按设备量化精度（1/255）校验，有效上界 = 曲线 + 1 LSB；偏差表中 `~` 表示超模型上界但在 1 LSB 内，`!` 表示硬越界。
