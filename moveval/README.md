# moveval

服务端移动合法性校验：按上次权威位置与允许速度计算可达圆，超范围判定非法并夹回，
包频率异常单独标记，合法移动一律放行，校验开销与单位数线性。

## 规则

- 可达范围：以单位上一个**权威位置**为圆心，`reach = max_speed × dt`
- 判定 `dist <= reach × 1.01 + ε`（含等号与 1% 相对余量，吸收客户端 float/量化漂移，任何速度尺度下均零误判），合法坐标原样放行
- 超范围样本：判定非法，投影到可达圆边界（朝声称方向走满 `reach`），客户端声称值永不进入权威状态
- 频率异常（EWMA 跟踪包间隔）：过快（重放/爆发）与异常长间隔分别置标志，**只标记不拦截**
- 非有限坐标（NaN/Inf）、时间不增的重放包：一律拦截，服务端时间不回拨
- 单位 id 即服务端分配的槽位号，单次校验 O(1)，批量 N 个单位 O(N)
