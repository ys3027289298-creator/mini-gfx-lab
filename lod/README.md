# lod

屏幕误差 LOD 选择 + 迟滞切换，以及多网格共享三角面预算。

- 单网格：按投影误差挑最粗的可接受级别；切换需超过 `tau` 的迟滞带，避免相机在阈值附近抖动。
- 多网格：整帧一个总三角面预算，先按 `可见像素面积 × 重要性` 分给各网格（每个网格预留最粗级别，预算不够时剔除可见性最低的网格），再做有上界的贪心交换——降一级某个网格、升一级另一个，直到没有正收益的交换为止。
- 每帧输出预算使用率（`usage`）、交换轮数（`iters`）和加权误差代价（`cost`，越低越好）；画质对比以同预算下平均分配的 `cost` 为基准。

```bash
make test
```

`make test` 会校验：50 网格同屏不超预算、交换迭代有上界且误差代价单调不升、极端紧预算下靠剔除保持不超、共享预算的画质损失比平均分配少两成以上。
