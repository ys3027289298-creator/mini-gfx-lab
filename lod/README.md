# lod

屏幕误差 LOD 选择 + 迟滞切换，以及四级网格的保守包围盒验证。

```bash
make test
```

## lod-selector

屏幕空间误差选级 + 迟滞，避免相机在阈值附近抖动时层级反复横跳。

## bbox-check

针对「边缘网格整块消失」的包围盒保守性验证。构造一个不保守的裁剪盒
（由向内取整的量化坐标构建，顶点位移未计入）作为故障对照，同时验证
带 epsilon 外扩的保守盒，对全部四个 LOD 级检查：

1. **顶点覆盖** — 该级每个顶点都在该级保守盒内（naive 盒存在泄漏）；
2. **投影不漏出** — 盒子投影矩形包住所有顶点的投影，无 projected leak；
3. **边缘不漏绘** — 沿屏幕四条边细步扫掠（步长小于量化步长），把盒裁剪
   决策与逐顶点真值比对：保守盒零次假裁剪，naive 盒稳定复现假裁剪；
   允许过度保留（宁大勿小），不允许漏绘；
4. **体积冗余** — 外扩带来的体积增量 ≤ 20%（当前约 6.4%）。

退出码 0 表示全部通过；naive 盒必须被检出失败，否则测试本身失去意义。
