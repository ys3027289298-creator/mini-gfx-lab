# lod

屏幕误差 LOD：离线变体自动生成管线 + 运行时零分配查表选择。

## 两个程序

| 源 | 程序 | 职责 |
|---|---|---|
| `src/lod.c` | `lod-selector` | 原有：手搓误差表上的屏幕误差选择 + 迟滞 |
| `src/lod_pipeline.c` | `lod-pipeline` | 自动生成管线：高模 → QEM 简化 → 变体集 blob → 运行时查表 |

```bash
make test
```

## 生成管线（离线，`lod-pipeline`）

1. **输入**：焊接好的三角网格（浮点 xyz 顶点 + 整数索引）。
2. **QEM 边折叠**：每个顶点累加邻接面的平面二次误差矩阵（quadric），
   开放网格额外加边界约束面防止边框塌陷；边的最优收缩点由 3×3 线性方程组
   解出，近奇异时回退到边中点（相对 pivot 容差，尺度无关）。所有边进最小堆，
   每次取全局最低误差的合法折叠。
3. **按误差目标逐级简化**：`lod_generate(..., err_targets, min_tris)`，
   误差目标是线性 RMS 世界尺度（内部与平方距离比较）。每级在下次折叠会越过
   该级目标、或面数触底时停止。
4. **变体集**：每级打包顶点、索引、AABB 包围盒、面数/顶点数、几何误差，
   序列化成单个小端 blob（magic/version 头 + 每级 52 字节记录 + 连续载荷）。
   `lod_blob_open` 做完整结构校验，损坏/截断/magic 不符一律拒绝。
5. **运行时**：`LodBlob` 只是调用方内存上的只读视图（32 字节，栈上即可）。
   `lod_select` 纯查表——每级预算好升/降切换距离，tau 宽死区提供迟滞，
   反汇编无任何 `call`，零分配；同距离重复查询结果恒定，不抖动。

## 自测覆盖（`./lod-pipeline` 打印 `RESULT: OK`）

- 五级变体，面数/顶点数/误差逐级严格单调，0 级与输入位级一致。
- 每级 AABB 覆盖该级全部顶点（带尺度相关容差），且每个轴极值被实际触达（紧致）。
- 所有索引落在本级顶点范围内；blob 文件往返一致。
- 坏 magic、截断 blob 被拒绝。
- 选择器：远距→最粗、近距→最精；死区内 200 次重复查询零切换；双侧迟滞。
- 开放网格（地形）与闭合网格（二十面体球，无边界边）两条路径都正确简化。
- 生成耗时与 30 s 预算：20k 三角形约 25 ms；250k 三角形约 0.7 s。
- ASan/UBSan 干净；运行时函数（`lod_select`/`lod_blob_open`）不引用任何分配器。
