# lod

离线简化 → 带索引的变体包 → 运行时按预算选级，一条链。

```bash
make test
```

## 三段

| 阶段 | 产物 | 何时跑 |
|---|---|---|
| `lod-bake` 离线简化 | 每个网格 N 级变体（顶点聚类）+ 几何误差 + 覆盖原网格的包围盒 | 构建期 |
| `lodfmt` 索引与存储 | `lod.pack`：头 + 网格表 + 级别表 + 顶点/索引块，小端、定长、带 CRC32 | 构建期写一次 |
| `lod-run` 运行时选级 | 按 `mesh_id` 查索引取级别，屏幕误差 + 迟滞选级，受总面数预算约束 | 每次相机变化 |

运行时二进制只链接 `lodfmt` 的读取端和 `lodrt`，不链接简化器——三类职责在链接层就分开了。

## 数据格式（`src/lodfmt.h`）

- 64 字节头：magic `LODPACK1`、版本、网格数/级别数、表偏移、数据偏移、文件长度、payload CRC32。
- 64 字节网格记录：`mesh_id`、级别数、源顶点/三角数、源包围盒、级别表偏移。
- 64 字节级别记录：级别序号、顶点/三角数、几何误差、包围盒、顶点/索引块偏移与字节数。
- 全部字段逐个小端写入，不依赖结构体 padding。

`lod_pack_validate` 是唯一的校验入口，烘焙端写完先自校验、运行端打开时再校验一次。它会拒绝：

- magic/版本/头部长度不符、文件长度不符、表长度不符、偏移越界或未对齐
- CRC32 不符（覆盖头部之后的全部字节）
- 网格 id 重复、级别表不连续、计数超上限
- 几何误差非单调递增（选级规则依赖这个不变量）
- 级别包围盒不覆盖源网格包围盒
- 三角索引 >= 顶点数

## 选级与预算（`src/lodrt.c`）

每实例先按屏幕误差 `geom_error * screen_h / (2 d tan(fov/2))` 选最粗的合格级别，跨越阈值需超过 `tau` 倍（迟滞，避免相机在阈值附近抖动）。随后若总面数超过 `budget`，反复把"每省一个三角形误差增幅最小"的实例降一级，直到装下或全部已到最粗级。装不下时返回 `LOD_ERR_COUNTS` 并在 `LodReport.tri_over` 报告超出量，不会假装成功。

## 自测覆盖

`./lod-bake`：变体面数递减、误差递增、确实比源网格简化；写盘自校验。

`./lod-run`：加载校验、索引查找、各段计时；逐字节改包后必须被拒（CRC、magic、版本、截断、包围盒缩水、越界索引）；宽松/紧张/不可行三档预算；迟滞切换次数；缺失网格。
