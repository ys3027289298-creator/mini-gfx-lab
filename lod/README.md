# lod

屏幕误差 LOD 选择 + 迟滞切换 + 每帧三角面硬预算。

```bash
make test
```

## 预算规则

- 每帧先按屏幕误差和迟滞算出全部网格的候选级，累加候选三角面总量。
- 总量超过 `budget` 时**整组候选被拒绝**，不会部分采纳；随后回退：
  1. 上一组已提交且仍可行的解（`RB_PREVIOUS`）；
  2. 没有可用上一组时，全部网格取最粗级（`RB_COARSEST`）；
  3. 连最粗级也超预算则本帧不输出可行解（`RB_NONE`），总量按 0 计。
- 候选级在独立函数里计算，被拒绝时不会改动迟滞状态，所以回退不会污染后续选择。
- 每次回退写入 `Selector.log[]`，并可通过 `log_out` 输出一行
  `rollback frame=… cand_tris=… budget=… used_tris=…`。

`make test` 检查：同输入两次运行逐帧选级完全一致；所有预算（含扫预算与逐帧变化的预算）下
发射总量都不超上限；回退次数、超预算帧数与日志条数三者相等；回退帧等于上一帧发射的集合。
