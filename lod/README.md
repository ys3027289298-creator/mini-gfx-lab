# lod

屏幕误差 LOD 选择 + 迟滞切换，以及屏幕空间顶点密度自适应简化。

```bash
make test
```

- `lod-selector`：按几何误差投影到屏幕后的像素误差选择层级，带迟滞避免切换抖动。
- `lod-adaptive`：闭合网格按**投影后顶点间距**决定简化强度（短于 `TARGET_PX` 的边可折叠）。
  轮廓边及其一环顶点锁定，且折叠若会让三角形跨越轮廓平面或法线转动过大则拒绝，
  因此简化后轮廓偏差实测 0.000px。折叠按每帧预算分摊到多帧，写入后缓冲，
  完成后在帧边界交换；绘制始终使用前缓冲，自检会校验前缓冲在任务期间逐帧未变。
