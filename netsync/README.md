# netsync

网络抖动与丢包下的状态同步：快照插值、丢包外推、外推超时回退与视觉修正。

- 快照插值：渲染时钟最多滞后最新快照一个 tick（50 ms），这是抖动缓冲的上界，
  不会随时间累积，也不会因缓冲而额外加延迟
- 丢包外推：用最近两个快照的平均速度做外推，最多 150 ms（3 tick）
- 外推超时：到达上限后冻结预测；收到权威快照时回退到权威播放位置，
  剩下的视觉跳变用 120 ms 线性衰减修正，避免瞬移
- 自检：逐帧与服务器真值比较（“逐帧收包”的客户端显示的正是真值），
  并把每一帧的误差与解析上界比较。上界由场景的真实速度/加速度峰值推出：
  插值割线误差 `amax·span²/8`、外推误差 `amax·(span·age/2 + age²)`、
  单样本保持误差 `vmax·hold`、未衰减完的修正偏移
- 输出回退次数、修正量与修正幅度，以及时钟前推次数（用于区分“抖动推时钟”与“回退”）
