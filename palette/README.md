# palette

图集主题换色：源色板按槽位映射到目标色板，支持逐色覆盖，色板之外的
像素保持原样；抗锯齿边缘按覆盖率重建混色。`make test` 跑自检。

## 规则

- `pal_build` 校验色板：长度必须一致（`PAL_ERR_LENGTH`），源/目标色板内
  颜色不得重复（`PAL_ERR_DUP_SRC` / `PAL_ERR_DUP_DST`），覆盖的键必须
  存在于源色板、同一键不得覆盖两次、覆盖目标不得与其它目标色撞色。
- 逐色覆盖（`PalOverride`）按颜色而非槽位生效，优先级高于槽位映射。
- 精确命中色板的像素硬替换；未命中且无法用混色解释的像素（含透明
  像素、背景色）原样保留。
- 边缘像素先反解覆盖率 `t`，再用统一的整数混色约定
  `(a*(255-t) + b*t + 127) / 255`（四舍五入）与新色混合，支持三种图集：
  - `PAL_BG_SOLID`：不透明底图，边缘是底色与图标色的混合；
  - `PAL_BG_STRAIGHT`：直通 alpha，RGB 为图标色、alpha 为覆盖率；
  - `PAL_BG_PREMUL`：预乘 alpha，RGB 已按覆盖率预乘。
- 反解要求所有通道按同一覆盖率精确往返，且解释唯一；有歧义或解释不了
  的像素不动，避免误伤杂色。
- `PalMap.enabled == 0` 时 `pal_apply` 直接返回，输出与输入逐字节相同。

## 自检

自检在 16×16 图集上覆盖三种背景模式，每块色板含实心区和两条不同覆盖率
的抗锯齿边，并掺入无法解释的杂色像素。替换结果与一份独立编写的"手工
导出"参考实现逐字节比较，杂色像素数为零（`*_zero_stray`）；另校验禁用
直通、覆盖生效和全部拒绝路径。
