# fontfallback

按字体族优先级匹配、缺字逐级回退。`make test` 跑自检。

- 族优先级：给定期望族名（含别名）时，匹配的字体排到链首，其余按加入顺序。
- 逐级回退：逐字体查码点，首个命中的字体提供全部字形数据；查不到画方块并报告 `U+XXXX`。
- 对齐：每个字体按自身 upem 缩放到统一的 1000 单位 em，基线固定在 y=0，回退字形与主字体字形在同一基线和推进网格上。
- 一致性：自检用 `merge_faces` 合并出等效的单字体全覆盖参照，逐字形比对位置、推进、墨迹框、基线以及整行行盒与行宽。
- 复杂度：查找顺序在链建立时缓存，单次查字形最多探测 `字体数` 次；自检用探测计数验证线性（1 字体 → 1 次，8 字体最坏 8 次，整行 36 次 ≤ 8×8）。
