# stuck

单位卡住检测与脱困的自包含实验平台。连续空间圆-瓦片碰撞模拟，叠加在
8 方向 A* 网格导航之上，固定随机种子，所有数字可复现。

## 机制

- **卡住检测（零误报）**：24 tick（1.2s）滚动窗口同时统计意图位移
  （期望速度×dt）与实际位移。仅在持续高意图（>0.4 vmax）且
  实际/意图行程比 < 0.25、窗口内意图累计 ≥ 0.6 格时判定卡住。
  零意图（编队停顿、到达、队友让行）立即重置窗口，正常走动、贴墙
  滑行、外部冻结、对向让行都不会触发。
- **脱困状态机（逐级升级）**：侧移 A → 侧移 B → 后退 → 标记需重规划。
  每个动作有时间预算与成功位移判定；同地点重复卡住会跳过侧移直接
  后退，第三次仍卡则立即请求重规划。重规划临时封堵失败方向后重跑 A*。
  脱困后有 0.5s 宽限期，避免恢复瞬间误触发。
- **队形保持**：车队沿共享路线按 lag 槽位行进，含跟车限速、硬间距
  守卫（任意意图下都不重叠）、脱困动作对队友让行；度量物理重叠、
  次序交换（边沿触发）和槽位偏差。

## 自检场景（7 个）

| 场景 | 目的 |
|---|---|
| S1 开阔地纵队行进 | 误报为零、队形保持 |
| S2 持续贴墙滑行 | 有接触但切向有位移，不触发 |
| S3 编队外部冻结 2s | 零意图不触发 |
| S4 两单位交叉让行 | 队友阻挡不触发 |
| S5 封闭 U 龛 | 侧移失败→后退脱困 |
| S6 定时闸门封死口袋 | 局部动作全失败→重规划标记 |
| S7 五单位纵队过内拐角 | 卡住检测+脱困全程不破坏队形 |

```bash
make test      # 跑全部场景，退出码 0 表示所有断言通过
STUCK_TRACE=1 ./stuck   # 打印每 tick 每单位的跟踪信息
```

输出含每个场景与汇总的：卡住次数、脱困成功率、脱困耗时
（tick/秒的 min/mean/max）、重规划标记数、队形指标。
