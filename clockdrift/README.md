# clockdrift

采样钟漂移补偿。输入/输出两侧时钟长期运行后累计帧数发散，导致输出侧零星
欠载或重复帧（波形"断一下"）。本模块按累计输入/输出样本数计算漂移：

- 漂移达到 1 帧即在当前块内纠正：输入快则**丢帧**、输入慢则**重复上一帧**，
  纠正点在块内均匀分布；纠正后残差严格小于 1 个采样（自检用两路独立时钟
  模型长时仿真与真实漂移对照验证）。
- `DriftCfg.enabled = 0` 时纯透传，输出与输入逐字节一致，不做任何插/丢。
- 漂移绝对值达到可配的 `drift_limit` 即返回故障并锁存（不再无限补偿），
  `dr_reset()` 复位前不触碰输出缓冲。
- `DriftStats` 暴露累计输入/输出帧数、残差漂移、累计丢帧数、插帧数与故障位。

`make test` 跑自检。
