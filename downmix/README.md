# mini-downmix

多声道 → 双耳下混矩阵，解决直接相加时低频互相抵消、人声偏移的问题。

```bash
make test
```

## 推导

1. **布局 → 向量基**：每个声道按方位角用 `spatial.c` 同源的 IID 模型取单位基
   `b_k = (gL, gR)`，满足 `gL² + gR² = 1`；方位角同时给出双耳到达时延
   `dL, dR`（Woodworth-lite，最大 0.6 ms）。
2. **矩阵**：`M[e][k] = √w_k · b[e][k]`，权重满足 `Σw_k = 1`。于是
   `tr(MMᵀ) = Σ_k w_k ‖b_k‖² = 1`，等功率不相关声道的输出功率恒等于单声道
   输入功率，不随声道数膨胀。
3. **相位对齐的层级**：静态矩阵本身没有时间维度，测试里并列三条路径——
   - **A 原始静态矩阵**：只做增益相加；
   - **B 单延迟 + 静态矩阵**：每声道取双耳到达时延均值
     `a_k = round((dL+dR)/2)` 做一个共享延迟。这是纯静态矩阵的最优形态，
     但只能表达公共相位；
   - **C 延迟矩阵**：每耳各自的到达时延接静态增益，即
     `y[e](t) = Σ_k M[e][k]·x_k(t − d_e[k])`，正是解析双耳参考的因式分解，
     稳态下严格相等。

   关键结论：两个相关声道的相对相位需要两个不同的延迟才能表达，单延迟结构
   （A/B）在数学上做不到。Ls/Rs 在 `f* = SR/54 ≈ 889 Hz` 出现 π 相位抵消时，
   A/B 的误差非零且在抵消点单列报告；C 的误差为零（解析与时域均验证）。

## 误差上界

对单位振幅正弦（角频率 ω），单耳复振幅之差满足

```
|M − R| ≤ Σ_k c_k |e^{−iωa_k} − e^{−iωd_k}| = 2 Σ_k c_k |sin(ω(a_k−d_k)/2)|
```

故路径 B 的功率误差上界为
`||M|²−|R|²| ≤ |M−R|·(|M|+|R)|`，测试在 50–800 Hz 扫频逐点验证实测值不越界；
低频抵消点逐耳列出 A/B/C 三条路径的误差与该上界。

## 拒绝规则

- 矩阵描述维度不是 `2 × layout.n` → `DMX_ERR_DIM`
- 权重和不为 1（容差 1e-4）→ `DMX_ERR_WSUM`
- 负权重 → `DMX_ERR_WNEG`

## 关闭矩阵

`render_dispatch(..., enabled=0, ...)` 走与 `spatial.c` 完全相同的 legacy
路径（共享带符号 ITD、原始 IID、软限幅），自测断言逐样本 bit 相等。
