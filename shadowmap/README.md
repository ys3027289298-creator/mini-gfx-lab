# shadowmap

按屏幕占比重新分配阴影贴图分辨率，替代统一分辨率的一刀切。

- 每个投射体投影到屏幕，统计可见包围盒占屏幕面积的比例；占比为 0（离屏、相机背后、屏幕尺寸非法等）直接报错。
- 按占比归一化分配 texel 配额，再映射到 `0/64/.../4096` 档分辨率。
- 总配额受 `cap` 约束；按重要性从高到低发放，配额不足时低重要性投射体逐档降级，最低降为 0（关闭阴影）。
- 与统一 `1024²` 基准比较，输出近处（屏幕占比 ≥ 20%）每 texel 覆盖的屏幕像素数、像素分类误差及改善百分比。
- `redistribute = 0` 时所有投射体沿用统一分辨率，渲染结果与旧画面逐字节一致。
- 配额为负（含关闭重分配后统一分辨率总量超上限）返回错误。
