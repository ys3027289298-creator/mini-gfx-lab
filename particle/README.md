# particle

固定容量粒子池 + 每帧发射配额 + 发射器优先级调度，以及绘制批次排序：
按 (混合模式, 纹理) 分组，组内用计数排序按深度从远到近排列。

```bash
make test
```

`make test` 打印：

| 输出 | 含义 |
|---|---|
| `draw_calls_before` / `after` | 创建顺序与排序后的连续批次段数 |
| `sort_us_min` | 1 万粒子排序 100 次取最小值（微秒） |
| `group_ok` | 每个批次连续出现一次，组内深度非递增 |
| `order_identical` | 与逐粒子全排序的 (组, 深度, 创建序) 结果逐项相同 |
| `pixel_diff` | 分组排序 vs 逐粒子排序的软件光栅结果，逐像素比较 |
| `order_matters_pixel_diff` | 未排序 vs 逐粒子排序的像素差（证明顺序确实影响画面） |
| `global_depth_sort_pixel_diff` | 只按深度、忽略批次的全局排序与逐粒子排序的差异 |

计数排序是稳定排序，深度相同的粒子保持创建顺序；深度量化为 1024
级，因此组内代价是 O(n + 1024) 而不是 O(n log n)。
