# particle

固定容量粒子池 + 每帧发射配额 + 发射器优先级调度 + 视锥可见性剔除。

```bash
make test
```

## 可见性剔除

每个粒子带一个包围圆 `(x, y, radius)`；视锥是 2D 的四个半平面（近、远、左、右）。

- **批剔除**：粒子按固定大小 `BATCH_SIZE` 分批。每批先算出包含所有成员圆的最小包围圆，
  再拿这个批包围圆对四个半平面做一次四平面测试；整批落在某个平面外就整批剔除。
  存活的批再逐粒子精确测试。
- **一致性**：批包围圆保证包含成员粒子圆，因此被整批剔除的批里不可能有可见粒子，
  精简剔除得到的可见集合与逐粒子测试完全相同（`cull_lockstep` / `cull_fuzz` 验证）。
  收紧的包围圆只会让批测试更严格、更快拒绝，不会藏起可见粒子。批包围圆留了
  一个小余量吸收浮点误差，方向是"更宽松"，正确性最终由逐粒子测试兜底。
- **冻结**：`update_visible()` 只积分可见列表；被剔粒子位置和 age 原样冻结，
  重新进入时从冻结点继续，因此轨迹与不剔除的逐粒子模拟逐位相同。
  若需要"被剔时也继续衰老"的策略，应替换 `update_visible()`。
- **线性**：每帧每个粒子最多被探测常数次（包围盒 + 包围圆 + 一次精确测试），
  剔除耗时随粒子数线性增长；`cull_scale` 用递增粒子数测 ns/particle 与计数不变性。

输出（`make test`）：

```
cull_lockstep_ok=1    # 批剔除 == 逐粒子剔除；冻结无漂移；冻结→可见过渡发生
cull_fuzz_ok=1        # 随机布局与随机相机下逐粒子一致，且确有整批被剔除
cull_scale_ok=1       # 每个粒子的探测/测试计数恒定，ns/particle 不随规模上升
```
