# particle

固定容量粒子池 + 每帧发射配额 + 三段式配额分配（每段都是 O(发射器数)，无排序）：

1. **优先级加权基础配额**：按 `priority × (1 + 已饥饿帧数)` 加权切分预算，需求封顶，地板余量用轮转游标逐个补发。
2. **最低保留配额 + 饥饿老化**：零配额发射器保留最低配额（MIN_QUOTA），饥饿越久权重越高，长期未获配额的自动被提升。
3. **帧间平滑 + 突发钳制**：每发射器配额不超过其 EMA 平滑值的 2 倍 + MIN_QUOTA，单帧总量硬钳在预算的 105% 以内（缩减时不击穿保留配额）。

```bash
make test
```

测试跑 10 发射器 × 1000 帧（预算周期性跌到 6、需求周期性 ×4 突发）验证：

- 每个发射器都拿到配额；
- 最长饥饿 ≤ 3 帧，并打印饥饿等待分布表；
- 突发帧总量 ≤ 预算 105%；
- 单帧分配耗时随发射器数线性（ns/emitter 基本恒定）。
