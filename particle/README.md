# particle

固定容量粒子池 + 每帧发射配额 + 发射器优先级调度，以及按相机距离的精度 LOD。

```bash
make test
```

## 距离 LOD

每个粒子按到相机的距离处于两档之一，阈值带迟滞（`near_d`/`far_d`，思路同 `lod/`）：

| 档位 | 更新频率 | 拖尾历史长度 |
|---|---|---|
| near（近，满精度） | 每帧积分，步长 `dt` | 16 个采样 |
| far（远，降精度） | 每 `FAR_PERIOD=4` 帧积分一次，单步步长 `4·dt`，按池索引错相 | 4 个采样 |

关键性质：

- **切换不跳变**：far 粒子的积分状态始终等于渲染位置，相位帧之间保持静止；切档不搬移任何位置，没有外插状态需要回补。`no-jump` 测试逐帧校验每帧位移只能是「静止 / 近程步 / 远程序块步」三种合法值，切换帧也不例外，并验证相对全精度参考的滞后不超过一个程序块。
- **画面误差有界**：位置误差即参考轨迹在相位帧上的量化误差，上界为 `最大速度 × (FAR_PERIOD-1) × dt`。`quality` 测试与同种子的全精度参考世界逐帧对比，实测最大偏差 0.125（上界 0.131）、RMS 0.020，死亡延迟不超过 3 帧。
- **性能**：
  - 积分步数与拖尾内存按 far 占比确定性下降，全 far 时各 −75%。
  - 拖尾环用独立 SoA 存储（`Trail trails[]`），热结构 `Particle` 仅 56 字节，物理扫描保持缓存友好。
  - 每粒子步长 `h` 无分支选择（编译为 `sete/and/cvtsi2ss`），`h==0` 在积分内部是廉价 no-op，随机近/远混合不会引发分支预测风暴；距离/tier 判定每 `TIER_EVAL_PERIOD=4` 帧才在独立一趟里跑一次。
  - 墙钟在 far 占多数的真实战场受益，在最坏的 50/50 混合下也只有有界的小幅开销，不会出现数量级回退。

`make test` 会跑优先级、迟滞、不跳变、画质、性能五项。可用 `-DMAX_PARTICLES=N` 覆盖池容量做规模压测（测试世界为静态存储）。
