# particle

固定容量粒子池 + 每帧发射配额 + 发射器优先级调度 + 发射器层级变换。

```bash
make test
```

## 层级变换

- 发射器持有相对父节点的局部刚体变换（位移 + 旋转），`emitter_set_parent`
  建立父子关系，父节点的位移与旋转自动带到子发射器及其全部粒子，无需逐帧手改坐标。
- 粒子在发射器局部坐标系中积分；`emitter_local_to_world` /
  `emitter_world_to_local` 做点互转，`emitter_vec_*` 做方向向量互转（向量只乘旋转矩阵）。
- 发射器旋转时粒子速度方向随之旋转（局部速度不变，世界速度经变换得出），
  与逐帧手算走同一套变换公式，结果完全一致。
- 层级深度硬上界 `MAX_HIERARCHY_DEPTH = 8`；自引用、循环引用和超限的父子关系
  在 `emitter_set_parent` 中直接拒绝（返回 -1，不改动现有状态）。
