# particle

固定容量粒子池 + 每帧发射配额 + 发射器优先级调度，以及重叠粒子的
近似深度剥离（order-independent transparency）。

## 近似深度剥离

透明粒子重叠时，按生成顺序混合会因深度顺序错误而产生色差。本模块不做
逐粒子排序，而是三趟处理（`composite_peel`）：

1. **分桶**：按深度把片段均匀分到 `B` 个等宽桶，桶数可配（`OitCfg.buckets`）；
2. **桶内塌缩**：桶内不排序——透过率 `T = Π(1−a)` 精确累乘，颜色按
   不透明度加权 `Σ(aᵢ·Cᵢ) / Σaᵢ`，得到该桶的一个等效层；
3. **逐桶合成**：桶层按深度 front-to-back 做 Porter–Duff over，共 B 趟。

总开销为 O(N + B)，无排序；`acc_ops == N`、`blend_ops <= B`。

由于桶透过率是精确乘积，结果 alpha 与逐粒子严格排序完全一致，只有 RGB
存在二阶小误差（同桶两粒子时 `|Δ| ≤ 2·a₁·a₂·|C₁−C₂|`），桶越多误差越小；
当每个占用桶只有一个片段时结果精确。误差随桶数单调下降，并可通过
`OitCfg.color_tol` 配置验收阈值。
