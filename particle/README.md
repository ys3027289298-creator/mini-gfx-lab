# particle

固定容量粒子池 + 每帧发射配额 + 发射器优先级调度。

更新阶段为无锁并行：池按槽位分成连续段，每线程只写自己那段（跨段只读），
同步只用两个原子计数器（generation / done），无互斥锁。随机数由
(槽位下标, 帧号) 哈希派生，不共享状态，因此任意线程数结果逐位一致。

```bash
make test
```

输出校验：

- `threads=N match=1` / `all_match=1` — 1/2/3/4/8 线程与单线程逐粒子逐帧完全一致
- `bench_match=1` — 基准场景下 4 线程与单线程最终状态一致
- `speedup_ok=1` — 4 线程每帧阻塞时间中位数 ≤ 单线程的 70%
