# falloff — 粒子贴图 alpha 径向衰减的指数标定

问题：粒子从发射器喷出后边缘有一圈硬边，像被裁掉 —— 贴图 alpha 沿半径没有衰减。
修复方向：alpha 沿半径做幂曲线衰减，指数由屏幕直径推。但两条效应互相牵制：

- 衰减越平缓（k 越小），单个粒子边缘越柔和，越好看；
- 衰减越平缓，多粒子加法混合叠加后簇中心越容易过曝。

```bash
make test
```

## 剖面

`a(u) = (1 - u)^k`，`u = r/R ∈ [0,1]`，R 为粒子屏幕半径。

## 关系 1：指数 ↔ 单粒子边缘宽度

边缘宽度定义为 alpha 从 0.9 降到 0.1 的径向带宽：

```
w(k) = R·(0.9^(1/k) − 0.1^(1/k)) ≈ ln(9)·R/k ≈ 2.197·R/k   (k ≳ 5)
```

k 越大边缘越窄（越硬）；k ≤ 1 时带宽可达 0.8R（非常软）。

## 关系 2：指数 ↔ 簇叠加中心亮度

N 个粒子均匀散布在半径 S 的簇内（S 由发射器物理决定，与粒子直径无关），加法混合：

```
E[B] = (2NR²/S²)·∫₀^q (1−t)^k·t dt,  q = min(1, S/R)
     = 2NR² / ((k+1)(k+2)·S²)                            (R ≤ S)
```

关键缩放：**B ∝ (R/k)²**。要钉住 B 必须让 k 随直径增长（k ∝ R）；
若 k 恒定（只按单粒子的相对柔和度优化），则 B ∝ R²，大直径簇中心必过曝。

## 定指数规则

```
k*(D) = 满足 E[B] ≤ B_target 的最小 k   （最软但不过曝）
并校验 w(k*) ≥ w_min                     （否则该直径下两目标不可兼得）
```

实验参数：B_max = 1.0（LDR 加法过曝点），B_target = 0.8（留 20% 余量），
w_min = 1.5px，N = 256，S = 32px。

联立两条关系的推论：钉住 E[B] ⇔ 钉住 R/k ⇔ 边缘宽度自动钉在固定像素数
（w ≈ 2.197·S·√(B_target/(2N)) ≈ 2.8px），与直径无关。

## 实测（三组六个数）

单粒子放大 8× 量边缘宽度；喷簇 101 次取中心亮度均值。

| 屏幕直径 D | 指数 k* | 单粒子边缘宽度 | 簇中心亮度 |
|---|---|---|---|
| 16  | 4.84  | 2.85 px | 0.737 |
| 48  | 17.48 | 2.82 px | 0.829 |
| 128 | 49.10 | 2.80 px | 0.783 |

三档边缘宽度都钉在 ≈2.8px（关系 1 验证），簇中心亮度都在上限 1.0 之内（关系 2 验证）。

注意：逐簇波动很大（单簇 range 0.06..2.9，约 1/4 的簇会瞬时超 1.0）——
这是峰值 alpha=1.0 时点采样叠加的泊松闪烁，均值受控不代表每簇都安全。
实际工程里应配合峰值 alpha < 1（更多更弱的粒子）或混合端软限幅。

## 对照：只按单粒子优化的下场

若指数只按单粒子观感定（相对柔和度恒定 w = 0.10R，即 k 恒定 ≈ 20.74）：

| D | k | 边缘宽度 | 簇中心亮度 |
|---|---|---|---|
| 16  | 20.74 | 0.80 px（< 1.5px，仍是硬边） | 0.094 |
| 48  | 20.74 | 2.40 px | 0.569 |
| 128 | 20.74 | 6.40 px | **4.232 > 1.0 过曝** |

大直径簇中心亮度超上限 —— 指数只按单粒子优化、没算叠加。
B ∝ R² 的缩放使大直径档必然爆掉，同时小直径档边缘带宽不足 1px 仍是硬边：
恒定 k 在两端都失败。正确做法即上面的规则：k 由屏幕直径推出（k ≈ 0.34·D）。
