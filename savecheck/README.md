# savecheck

场景检查点 / 回滚：把 `World` 的全部可变状态打包成检查点，回滚后与"重新初始化再推进到同一 tick"逐字段一致；差异包只存变化量。

```bash
make test
```

## 设计

- **状态即单元格**：`World` 里每个可变值映射到一个 u32 单元格（float 按位）。单元格顺序固定为 `meta → entity → emitter → particle → derived`，因此字段名稳定（如 `ent.1.hp`），delta 为 `(单元格下标, 值)`。
- **包格式**：`MGSC` + 版本 + 场景名 + 场景摘要 + 基址来源（delta 才有：基准哈希、基准 tick）+ 分块（meta/ent/emit/part/anim）。每块有自校验哈希，整包尾部再挂一个总哈希。读取端对越界、截断、坏版本、场景不符、基准不符都返回原因串。
- **完整包**：直接写全部单元格，回滚即精确还原。
- **差异包**：每块写成"变化位图 + 只写发生变化的 u32 值"，未变化单元格由基准检查点补全；`delta_changed_cells` 与直接逐字段比较得到的差异数一致，解码时也拒绝错误基准。
- **派生字段校验**：`anim.frame`（由 `anim_t` 和关键帧曲线算出）与 `solid`（由几何算出）不单独信任，回滚时重算并与包内值比对；关键帧数量对不上场景也会报错，防止状态与内容脱钩。

## 自检覆盖

- 60/90/120/150 tick 的完整包，回滚后与 `world_play` 直达同一 tick 的结果逐字段比较为 0 差异，哈希一致。
- 回滚后继续推进 30 tick，与直接推进到 120 tick 无漂移；从 delta 回滚后继续推进 20 tick 同样无漂移。
- 90→120 的 delta 只因此产生的 118 项变化，独立解析包字节统计存储值也是 118；相同状态的 delta 存 0 项。
- 篡改一个 hp 位，比较器能定位到 `ent.1.hp`。
- 坏包/截断/坏版本/无基准/错误基准/场景不符/派生字段不符均被拒绝并给出原因。
- 报告 `checkpoint_bytes`、`delta_bytes`、`delta_saving_pct`、`restore_us_full`、`restore_us_delta`。
