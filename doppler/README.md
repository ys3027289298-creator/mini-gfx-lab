# doppler

移动声源多普勒：轨迹跟踪与平滑，替代每块取整延迟、参数块内恒定的朴素实现（一卡一卡）。

## 管线（按块更新，块内连续）

1. 关键帧分段线性轨迹给出每块目标位置，位置差分得到原始速度
2. 突然变速先按每块最大速度增量 `max_dv` 限幅，再过一阶低通
   （时间常数 τ，`alpha = h/(τ+h)`）；位置用梯形积分推进，无一拍滞后
3. 传播延迟 D 与增益 `g = 1/(1+cD)` 在块端点对真实轨迹解 retarded-time
   方程 `|r(t−D)| = cD`（单调二分），块内逐样本线性斜坡——块 n 的终点
   即块 n+1 的起点，块边界零跳变
4. 分数延迟读指针连续移动、线性插值读环形缓冲；亚声速下读指针单调，
   轨迹折返也不跳变
5. 预卷：t=0 前缓冲 `PREROLL` 个样本，轨迹带负时间关键帧，测试窗口内
   每个发射时刻都有确定的声源位置和有效输入样本

## 误差上界（相对逐样本精确物理）

线性轨迹上 D(t) 是二次函数，斜坡余项满足 Taylor 界：

- 延迟斜坡：`|ΔD| ≤ h²/8 · max|D″|`
- 增益斜坡：同形式
- 分数插值：线性插值界 `w²/8 · max|x″|`
- 含关键帧的 kink 块：斜坡落在端点范围内，误差以端点差为界
- 总输出误差另设硬上界

自检对每条轨迹在段内用二阶差分实测 `D″`、`g″` 并核对上述不等式。
