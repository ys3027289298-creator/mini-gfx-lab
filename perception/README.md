# mini-perception

守卫感知模型：视锥（距离/角度衰减 + 视线遮挡）、听觉事件（半径衰减）、
觉察度电表（分段常值 ODE，发现时刻与帧率无关）、记忆过期与再发现。

```bash
make test
```

## 模型

- **视觉刺激** `s = (1 - d/range) · (1 - |θ|/半锥角) · 显眼度`，超出视距、
  视锥外或被网格遮挡（DDA 射线）时严格为 0。
- **听觉**：一次性事件，`d ≤ radius` 时按 `loudness · (1 - d/radius)` 全向
  接收（穿墙），以脉冲形式计入觉察度并刷新最后已知位置。
- **觉察度**：`da/dt = rise_rate · s`（无刺激时以 `decay_rate` 衰减）。
  常值刺激下欧拉积分就是精确解，解析发现时刻
  `t = (阈值 - a) / (rise_rate · s)`，自测用 60/30/10 fps 验证步进结果都
  落在解析时刻所在帧。
- **状态机**：`UNAWARE → SUSPICIOUS → DETECTED`；失去刺激进入 `MEMORY`，
  持有最后已知位置并倒计时，窗口内重新感知保留残量、识别更快；记忆过期
  后电表硬归零，再发现重新计满完整延迟。
