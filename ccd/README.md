# ccd

粒子对障碍物的宽窄两级碰撞管线。

- 宽相位：把粒子的扫掠 AABB 与障碍物 AABB 按左边界排序，扫描线求交，输出候选对。
- 两级之间：每个候选携带粒子扫掠盒与障碍物包围盒，窄相位先复核再继续。
- 窄相位：连续检测（线段 vs 圆），快速或细小的粒子不会穿透。
- 每帧同时用暴力逐对窄相位求解，两路接触集合必须逐位一致；同时统计宽相位漏检数和离散检测会漏掉的接触数。

```bash
make test
```

输出为 `key=value`，包含 10000 粒子 / 1000 障碍的单帧耗时（宽相位、窄相位、管线、暴力）、候选对数量与漏检计数；`all_ok=1` 表示全部通过。
