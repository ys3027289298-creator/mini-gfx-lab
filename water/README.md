# water

二维水面反射：把水面线以上的场景镜像进水面区域，按波浪扰动采样，再按菲涅尔权重向深水色混合。

## 做法

- **镜像场景层**：水面以下像素 `(x, y)` 采样场景 `(x, 2*waterline - y)`。
- **波浪扰动**：每行预计算正弦偏移 `ox/oy`（幅度 `amplitude` 像素、周期 `wavelength`、速度 `speed` 均可配），采样坐标越界时钳制而不回绕，避免边缘失真。
- **菲涅尔权重**：Schlick 式权重 `f0 + (1-f0)*v^5`，`v` 为归一化水深——贴近水面看到的是水色，远处（掠射角）反射趋近于 1。
- **两条路径**：`water_reflect_ref` 逐像素浮点参考实现；`water_reflect_opt` 行 LUT + 定点混合，每像素一次采样，测试锁定两者差异 ≤ 1 LSB。

## 自测

```
make test
```

覆盖：零幅度时与手工逐像素镜像完全一致、优化路径与参考一致、幅度可配且零幅度无残留扰动、极端幅度下采样不越界不失真、菲涅尔单调性、反射开销不超过场景绘制的 30%。
