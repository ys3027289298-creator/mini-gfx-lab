# motionblur

逐像素速度场的运动模糊：每个输出像素沿自身速度 `(vx, vy)` 在快门时间
`T` 内做线积分，核长 `L = |v|·T` 随速率变化，采样权重归一保持能量。

```bash
make test
```

## 模型

输出像素 x 处的曝光值（`t ∈ [-T/2, T/2]` 为快门时间）：

```
out(x) = ∫ I(x − v(x)·t) dt / ∫ dt
```

- 中点求积，`samples` 个采样点均匀覆盖快门区间；
- 采样处双线性插值，图外按边缘像素钳制；
- 权重显式求和归一（`wsum`），保证平坦输入的 DC 增益为 1；
- `speed = 0`（或 `L = 0`）的像素直接拷贝，不被糊；
- `enabled = 0` 时整图 `memcpy`，与输入逐位相同；
- 预检在写输出前完成：尺寸、`samples ∈ [1, 256]`、`shutter ≥ 0`、
  NaN/inf 速度、`max_speed` / `max_kernel` 越界一律拒绝，`out` 保持原样。

## 参考图与误差分解（测试）

以阶跃边 `I(q) = [q ≥ edge]` 为信号：

| 参考 | 含义 |
|---|---|
| `ref_frozen_step` | 冻结速度（核内速度恒定为该像素值）对**理想阶跃**的解析积分 |
| `ref_recon_step` | 同一冻结核对**双线性重建后的光栅化阶跃**的解析积分 |
| `ref_trajectory_step` | 变速场 `v(x)=v0+kx` 下沿真实轨迹 `dX/dt=v(X)` 的解析曝光 |

离散核与真实曝光的逐像素最大误差被拆成三项（三角不等式）：

1. **模型偏差** `|F − E|`：冻结速度假设的固有误差，只在变速段出现，
   匀速段恒为 0——即“匀速凑合、变速露馅”的量化位置；
2. **重建偏差** `|G − F|`：双线性插值把阶跃变成 1px 斜坡带来的固定
   偏差底，不随采样数下降；
3. **求积离散** `|out − G|`：有限 N 的时间采样误差。双线性重建后的
   阶跃是分段线性信号，中点求积对线性函数精确，此项在阶跃测试中仅余
   浮点舍入；在 2D 正弦场（有曲率）上才显现，且随 N 增大而下降
   （测试比较 N=1 单点矩形规则与 N=32）。

另有 2D 正弦场斜向匀速模糊与解析线积分（含 sinc 衰减）的对照，以及
静止像素逐位保留、关闭直通、越界拒绝、能量归一的断言。

## 偏差来源说明

- **变速模型偏差**：核内把速度冻结为输出像素的瞬时值，实际曝光期间
  像素穿越的路径由局部速度梯度决定；`v(x)=v0+kx` 下解析解是轨迹
  穿越边缘的时间占比，两者差随 `k·T` 增大；
- **双线性重建**：参考用的是连续理想阶跃，离散管线只能采样插值后的
  分段线性信号，该偏差有固定下限；
- **时间求积**：N 有限时的采样近似。对双线性重建产生的分段线性信号
  中点规则精确成立（阶跃测试里误差为浮点舍入级）；对有曲率的信号
  （正弦测试）为 O(N⁻²)，N=1 退化为单点矩形规则，误差显著放大；
- **边界钳制**：核伸出画面时按边缘像素延拓，会压低边界像素的对比度。
