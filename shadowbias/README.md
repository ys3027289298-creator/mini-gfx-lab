# shadowbias

按光线入射角与深度斜率自适应的阴影贴图 bias（software shadow-map 仿真）。

## 要解决的问题

薄墙上手工固定 bias 两难：

- bias 小 → 深度量化误差造成自阴影，墙面出现条纹（acne / streaking）；
- bias 大 → 阴影与投射体脱节、墙根漏光（peter-panning / light leak）。

## 仿真设置

- 场景：地面 + 三道 0.06 单位厚的墙（薄到只占 ~0.16 个阴影纹素）+ 悬空遮挡体；
- 每帧按正交光渲染 **两张** 64×64、12 bit 深度图：仅地面、仅墙体。
  分两张是为了把「接收器自身表面的量化 acne」与「真实遮挡」干净分离，
  避免两个表面共享纹素造成无法用 bias 修复的混叠；
- 相机画面 120×90，6 帧不同光高角（±12° … ±60°），逐像素与光线追踪
  ground truth 对照。

## 自适应 bias

每个深度纹素：

1. 由邻域深度做**逐轴中心差分**得到深度斜率 `|∇z|`（某一轴邻域为空或
   跨轮廓时只丢弃该轴，另一轴仍可用）；
2. 由纹素法线与光线夹角得 `tan θ`（正对 = 0，斜射增大）；
3. `bias = clamp(BASE + slope_scale · max(|∇z|, tan θ), …, cap)`，单位为
   深度量化级 quanta。正对时退到常量 BASE，斜射时随斜率增大；
4. `slope_scale` 不是魔数，由深度图参数推导：
   `qdepth · texel_world_size / 2 · SLOPE_K`，即覆盖一个纹素内量化误差
   所需的理论 bias；
5. 斜率算不出来（纹素在图边界、两轴邻域都为空/都跨轮廓、结果非有限）时
   回退固定值 `BASE + slope_scale·tan(FALLBACK_DEG)`，并对每次回退计数。

另一个关键区分：**遮挡查询不加 bias**。bias 只用于抵消接收器自身表面的
量化 acne；用墙体深度图查询地面时加 bias 只会把接触阴影从墙根推远。

## 对照统计

固定 bias 先做 0…128 quanta 扫描，取总错误最小者作为「手工调参」参照
（本场景为 128），再与自适应逐像素比较。每个像素分为：

- 条纹（streak）：判为阴影但真值为亮；
- 漏光（leak）：判为亮但真值为阴影。

6 帧 54384 个受测像素的实测：

| 方案 | 条纹 | 漏光 | 总错误 | 回退次数 |
|---|---|---|---|---|
| 手工固定 128q | 344 | 301 | 645 | — |
| 自适应 | 306 | 301 | 607 | 2005 |

条纹与漏光均不劣于手工值，总错误下降；墙面 acne（最难点）82 → 44。

## 运行

```bash
make test     # 固定 bias 扫描 + 逐帧对照 + 全部检查项
make dump     # 额外输出 out/frameN.ppm（四行：真值/固定/自适应/差异图）
make verify   # 独立 Python 校验：差异图红/橙像素数 == 程序报告的条纹/漏光数
```

差异图中红色 = 条纹，橙色 = 漏光，灰阶 = 与真值一致。
