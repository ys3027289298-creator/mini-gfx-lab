# skinning

CPU 线性混合蒙皮（LBS）。`make test` 跑自检。

处理管线（逐顶点）：

1. **四骨截断**：影响数超过 4 时按权重取最强的 4 条（权重相同按骨索引升序，保证确定性），
   被截断的顶点、截断前后条数记入 `SkinStats` 日志；
2. **权重归一**：对截断后的权重归一到和为 1；总权重为 0 的顶点走单位阵回退，
   不做 0/0 除法，因此不会产生 NaN；
3. **矩阵混合**：骨矩阵按权重线性混合后变换位置与法线，法线输出做单位化。

自检覆盖：

- 混合矩阵路径与逐顶点手工加权参考实现逐分量一致；
- 打乱影响顺序（管线级、混合级两组）结果不变，混合顺序不影响结果；
- 超过 4 骨的输入被截断且日志记录正确，截断后权重仍归一；
- 零权重顶点保持原姿势、输出全为有限值；
- 1 万顶点单帧蒙皮耗时（首帧与 200 帧平均）与截断预处理耗时，单位毫秒。
