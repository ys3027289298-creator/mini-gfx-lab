# tilemap

`make test` 跑自检，`make check` 跑回归脚本。

## 脏块增量顶点上传

瓦片地图几何体放在一块共享顶点缓冲里，按 8×8 图块的区块切成固定槽位区间；
每格固定 4 个顶点，每区块固定 24 条索引。区块内槽位顺序固定为
"层 → 行 → 列"，所以重建一个区块只会覆盖它自己的那段字节，索引缓冲一次生成后
不再重传。

顶点格式（8 字节）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `x`,`y` | int16 | 左上角像素坐标（每格 8 px） |
| `tile` | u8 | 图块 id |
| `variant` | u8 | 4 邻接自动拼接 mask（0–15） |
| `layer` | u8 | 所属层 |
| `w` | u8 | 1 = 有图块，0 = 空槽 |

### 脏标记

`map_set` 标记所在区块；若被改的格子落在区块边界，则同时标记跨边界相邻的区块，
因为边界另一侧图块的 4 邻接 mask 会随这一格改变。顶点之外的四个角（地图外缘）
不涉及邻块。漏标时检查脚本会报出接缝。

### 上传范围

每个脏区块重建到临时缓冲，然后与上次上传的镜像逐字节比较，只 memcpy 不同的
连续区间，并把这些区间的字节数累加进 `uploaded_vb_bytes`。区块被标脏但内容
没变（例如同一帧内改回原值）时上传 0 字节。

索引缓冲生成后不变，增量路径上 `uploaded_ib_bytes` 恒为 0；全量路径按
`VB_BYTES + IB_BYTES` 计。

### 开关与一致性

| 开关 | 行为 |
|---|---|
| 默认 | 增量路径 |
| `--no-dirty` / `NO_DIRTY=1` | 关闭增量路径，输出与改造前逐字节相同 |
| `--legacy` | 只跑改造前的那 12 项自检，输出与冻结基线逐字节相同 |
| `--seam-scan` | 扫描 GPU 侧几何体与地图真值，有陈旧顶点的格子数非 0 则退出码 1 |
| `--seam-scan --inject-seam` | 故意丢掉跨边界标记，检查脚本必须检出 |

增量路径与全量路径产出的 `gpu_vb` / `gpu_ib` 逐字节相同，渲染出的
384×384 软件光栅图逐像素相同；这两个比较在每个测试帧都做。

### 实测重传量

32×32 地图、3 层，全量一帧 98,304 B 顶点 + 36,864 B 索引 = 135,168 B。

| 场景 | 重建区块 | 上传顶点字节 | 相对全量 |
|---|---|---|---|
| 区块内部改一格（3×3 相邻图块） | 1 | 24 | 0.024% |
| 跨区块边界补一格（4 面邻居） | 3 | 36 | 0.037% |
| 角色沿 y=8 横穿 32 格，每帧走一格 | 76（累计） | 252（累计） | 99.994% 省 |
| 400 帧伪随机编辑 | — | 5,750（累计） | 99.989% 省 |

角色行走时单帧上传 4–8 字节：只重传被改的两格（旧位置恢复、新位置标记），
由于这两格都在区块边界，会重建 2 个区块，但另一个区块内容不变、上传 0 字节。
