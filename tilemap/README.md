## 变体缓存

autotile 变体只依赖本格与 4 邻居，因此维护按格的变体缓存
（`variant` + `vvalid`）：

- `map_set` 仅在填充状态（空/非空）翻转时，精确失效本格及 4 个邻居，
  边界处只失效界内格，重复失效去重；填充状态不变（空写空、非零 id 互换）
  不失效任何格；层间隔离。
- `autotile_variant` 缓存命中直接返回，未命中只重算该格。
- 自检用两份地图跑同一条随机编辑序列：缓存路径（仅重算脏格）对照全量
  重算路径（每步重算全部 3072 格），逐格校验变体一致，并输出两者重建
  格子数对照（单次编辑典型为 5 vs 3072）。
