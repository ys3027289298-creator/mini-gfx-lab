# tilemap

分层瓦片地图：4 邻接自动拼接、区域剔除，以及多页图集管理。

```bash
make test
```

## 多页图集

单页实现是一个 8×8 网格、40 个瓦片 id 全部常驻，页一旦放满只能整页重建。
多页管理器把同样的瓦片拆到若干 4×4 页（每页 16 槽），只重建真正 miss 的那一页。

- **按频次分配（prefill）**：统计地图上每个 id 的出现次数，按频次降序入页，
  最热的 id 落在 page 0；槽位不足时最冷的 id 不常驻。`prefill_freq_ordered`
  /`prefill_hot_on_page0`/`prefill_no_duplicate` 校验分配结果。
- **跨页引用解析**：全局 id → (page, slot) 查找，解析时维护当前页绑定，
  绑定变化计入 `switches`；命中只更新 LRU 时钟，不触发重建。
- **页满替换（代价策略）**：先选出持有全局最低代价槽位的页（代价 = 频次，
  同频按 LRU 最久未用），再只在该页内淘汰，抖动集中在最冷页、热页保持常驻。
  对照基线为不看频次的随机淘汰（`POLICY_NAIVE`）。
- **逐像素一致**：每个 id 有确定性的 8×8 像素图案，单页与多页两条路径渲染
  同一组 16 帧（滑动视口 + 全图双层），帧缓冲逐字节比较，`pixel_identical_all=1`。

### 对照数据（确定性场景，40 id，xorshift 固定种子）

| 配置 | 初始建页数 | 页切换次数 | 页重建次数 | 单帧最多触页 |
|---|---|---|---|---|
| single16（单页 16 槽，整页重建） | 1 | 0 | 237 | 1 |
| multi2 + 代价替换 | 2 | 466 | 25 | 2 |
| multi3 + 代价替换 | 3 | 467 | 0 | 3 |
| multi4（64 槽 > 40 id，全常驻） | 3 | 467 | 0 | 3 |
| multi2 + 随机淘汰（基线） | 2 | 536 | 33 | 2 |

要点：单页零切换但每次 miss 都整页重建（237 次）；两页把重建压到 25 次，
代价是渲染序列在两页间来回绑定；页容量一旦覆盖全部 id（3 页 48 槽）重建归零。
代价替换在切换与重建两个指标上都优于随机基线。ASan/UBSan 下无告警，
两次运行计数器与帧输出完全一致。
