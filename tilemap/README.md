## 碰撞形状合并

`colliders_build()` 对每个 layer 扫一遍：材质 = `layer * 256 + tile id`，按材质升序、逐格做贪心最大矩形扩张（先向右扩同材质且未占用的连续段，再逐行向下扩）。每个格子恰好归属一个矩形，所以合并前后覆盖面积完全一致，也不会产生重叠或空洞。

- 按材质分组：矩形内不会混入别的材质，输出也按材质升序排列。
- 层隔离：不同 layer 的材质键不同，永不合并。
- `colliders_build_per_tile()` 是不合并的对照实现；自检对全图逐点做命中检测（含越界点和目标材质判定），要求合并版与不合并的结果完全一致。
- 对照数字：测试场景 52 个逐格碰撞体合并成 6 个，自检打印 `collider_merged=6 collider_per_tile=52`。
