# tilemap

分层瓦片地图：4 邻接自动拼接、区域剔除，以及两种渲染路径——

- `render_unified`：收集可见图块后按统一深度键排序绘制。键为
  `[31] 透明组 | [30..12] z | [11..0] 格子序号`，透明/不透明分组与跨层遮挡
  都由同一把键决定；`z_base[layer]` 默认等于层号，可覆盖以改变层间前后关系。
  排序用稳定 LSD 基数排序，同键保持收集顺序，移动次数恒为 4n（线性）。
- `render_layered`：旧的逐层绘制，保留作对照。

自检覆盖：两版画面逐像素一致（透明已在正确前后关系的场景）、跨层遮挡修复、
z 键驱动遮挡、同键稳定可复现、排序开销随透明层数线性。

`make test` 跑自检。
