# tween

`make test` 跑自检。

关键帧时间线（`Timeline`）之外还有一个带时间缩放的播放器（`Player`），
可用于过场动画的快进/暂停/跳转：

- `pl_set_speed(p, s)`：`s = 0` 暂停，`s > 0` 倍速前进，`s < 0` 倒放
  （事件按时间逆序触发；循环时间线绕回末尾，非循环在 0 处钳制停住）。
- `pl_update(p, dt)`：播放头前进 `dt * speed`，事件按缩放后的时间触发；
  负 `dt` 定义为忽略。
- `pl_seek(p, t)`：跳转到 `t`，路径上跨过的事件全部按经过顺序补齐。

事件在播放头"到达或越过"其时刻时触发（前向区间 `(old, new]`，反向
`[new, old)`），因此同一时间线完整播放一遍，每个事件恰好触发一次，
与倍速无关。
