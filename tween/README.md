# tween

两个可独立构建、可自测的动画组件。

- `src/tween.c` — 关键帧时间线：缓动、循环、钳制。
- `src/fsm.c` — 条件驱动的状态机，建在同一套缓动之上。

`make test` 跑两者的自检。

## fsm 语义

- 状态持有目标参数向量（4 维）；转移带过渡时长与缓动函数。
- `current` 是逻辑状态：混合期间停在源状态，混合到达后才变成目标状态。
- 混合期间条件照常求值，源状态的另一条转移可以打断它；新混合从当前输出出发，
  因此参数不会跳变。
- 每拍只对条件取一次快照、最多触发一条正时长转移（插入顺序优先），同源两条边
  不会在一拍内互相打断；正在混合的那条边会被跳过，条件保持不会重启混合。
- 零时长转移在同一拍内串联，每拍最多触发 `FSM_MAX_STEPS`（32）次，转移成环也必有
  步数上界，不会死循环。
- 非法接线在构造期拒绝：越界状态号、负时长、空条件、零时长自环。

自检覆盖：基础插值与缓动、混合打断的连续性、细粒度输出连续、1000 次伪随机遍历
无非法状态、零时长环的步数上界、非法接线拒绝。
