# airabs

远距离声源的空气吸收（ISO 9613-1:1993），与几何距离衰减叠加。

## 接口

- `airabs_climate_set(c, t_c, rh, p_kpa)`：按温度（°C，-20..50）、相对
  湿度（%，0..100）、气压（kPa，50..200）计算 8 个倍频程（63 Hz–8 kHz）
  的衰减系数。越界或 NaN 返回 `AIRABS_E_PARAM`；相同气候重复调用走缓存。
- `airabs_update(m, c, distance)`：按距离算各频段空气衰减（dB），与逆
  距离几何衰减 `1/(1+d)`（与 spatial 模块一致）叠加，输出每频段线性增益。
  距离变化小于 1 cm 时复用缓存。
- `airabs_apply(m, buf, frames)`：可选的一阶低通 air shelf，把高频滚降
  作用到交错立体声采样块；系数按 4 kHz 频段解析求解，惰性触发并保持状态。
- `airabs_table_dev(c, rh, dev)`：与 ISO 9613-1 表 1（20 °C，RH
  30/50/70%）逐频段对比，输出有符号相对偏差。
- `airabs_geo_db(m)`：查询时才计算的几何衰减 dB，不占每帧热路径。

## 实现要点与预算

- ISO 物理（含 O₂/N₂ 弛豫频率）只在气候变化时计算，结果缓存为
  nepers/m。
- 每帧热路径无 transcendental 库调用：几何 1 次除法 + 8 次无分支多项式
  快速 exp（5 阶泰勒倒数 + 固定 1/8 缩放 + 三次平方，全域相对误差
  <1.5%，自检覆盖）。shelf 的 sqrt 只在真正滤波且距离变化时发生。
- 自检以 spatial.c 的真实帧（8 声源、方位三角、IID/ITD、立体声渲染、
  soft-clip）为基线，7 轮取最小值：稳态帧开销约 1.2%，声源每帧移动的
  最坏情况约 9%，均 ≤10%。
- 与表 1 的偏差全频段 ≤1.4%。
