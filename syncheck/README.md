# syncheck

渲染数据（实心瓦片）与碰撞数据（碰撞体矩形）双份存储的一致性校验。

- `validate()`：碰撞体栅格化后逐格比对，标出 `RENDER_ONLY`（有实心瓦片无碰撞）与 `COLLISION_ONLY`（有碰撞无实心瓦片），并统计越界碰撞体。
- `manual_cell()`：逐格朴素核对参考实现，测试用它逐格验证快速路径结果一致。
- `region_summary()`：差异按 16×16 区域汇总。
- `suggest_fixes()`：把同类差异合并成最大矩形，给出修复建议（补碰撞体 / 清实心瓦片，或反向操作）。

## 构建与自测

```
make test
```

自测包含：与逐格手工核对结果一致（含 100×100 全图）、区域汇总与全局计数一致、建议矩形精确覆盖差异格、一万格校验耗时 < 50ms。
