# cull

屏幕空间粒子裁剪预算：

- **可见性剔除**：投影包围圆完全在视口外的粒子直接丢弃。
- **投影尺寸剔除**：`alpha * (投影半径 + 0.5px) < 0.5/255` 的粒子对任何像素的贡献不足半个 LSB，渲染即白算，丢弃。
- **超预算丢弃**：幸存者可渲染数超过每帧预算时，按重要性（`priority * alpha * 投影面积`）用 quickselect（平均 O(n)，不做全排序）保留前 N 个，其余丢弃。
- **丢弃计数**：按原因分别统计 `offscreen / subvisible / budget_dropped`。

自测（`make test`）：

1. 软件渲染全量集合与裁剪后集合到 320x180 帧缓冲，逐像素对比，差异像素（容差 4/255）必须低于 1%。
2. 对 22000 个粒子连续裁剪 400 帧，单帧裁剪耗时（含最差帧）必须低于 0.2 ms。
