# inputbuf

帧驱动的输入缓冲与指令队列，面向连招快输入场景。`make test` 跑自检。

## 机制

- **缓冲窗口（帧）**：指令入队时记录 `expires = issued + window`，窗口内角色
  恢复空闲即可消费；超过该帧即超时丢弃并计入 `expired`
- **同帧合并**：同一帧内多个输入按优先级合并（高优先级胜出，同优先级取最新），
  被合并者计入 `merged`
- **固定容量队列**：满队时高优先级指令挤掉队中最弱指令（`evicted`），更弱的
  输入直接拒绝（`full`），两类分开计数
- **一致性**：缓冲命中与即时输入走同一个 `try_execute()`，并以 window=0 的
  即时模型做 oracle 回放，动作、帧号、角色锁定状态完全一致
- **窗口可调**：已在队指令保留旧到期帧，之后入队的指令用新窗口；同一输入脚本
  在 0/1/2/4/8 帧窗口下输出对比表，且更宽窗口的执行数不减少、丢弃数不增加

## 统计口径

`submitted = executed + expired + merged + evicted + full`，自检逐场景校验
该恒等式；`dropped` 为后四项之和，即丢掉的输入次数。
