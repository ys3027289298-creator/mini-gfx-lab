# decal

投射体生成贴花 + 固定容量池 + 生命周期衰减 + 最旧驱逐。

```bash
make test
```

## 要点

- **按投射体生成**：`decal_spawn_ray` 从相机/枪口沿射线找最近的表面，贴花记录所属 `target`
  序号，只画在这块表面上，不会穿透到下面的地板。
- **生命周期**：`age` 到 `life - fade` 后线性降到 0，到 `life` 后回收，贴花不再绘制。
- **最旧驱逐**：池满时按插入序号（`serial`）踢掉最早的一个，新贴花仍照常生成。
- **不留残影**：每片贴花带一张 16×16 的可见性纹理，生成时逐 texel 判断贴花四边形是否
  落在目标表面内；被裁剪到边缘外的 texel 直接不画。贴画的来源是 pool 自己的可见性表，
  `shade_reference` 用"手工放置 + 按目标裁剪"的对照渲染器复算同一点，二者必须一致
  （`manual_render_matches_pool`），所以驱逐/respawn 复用槽位后也不会留下上一片的像素。
- **容量满时单帧耗时**：自检最后 600 帧里池保持在上限，每帧生成、回收并做 24×24 的表面
  采样，打印 `cap_frame_ms_avg` / `cap_frame_ms_max`。
