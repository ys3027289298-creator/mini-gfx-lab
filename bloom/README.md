# bloom

带阈值保护的软膝（soft-knee）光晕。修复"暗部被模糊结果直接相加而整体发灰"的问题：
下限不凭感觉调，而是由可容忍灰阶抬高量 ε 解析反解。

```bash
make test          # 库自测
./bloom selftest   # 同上
```

## 管线（单通道，灰度 0..255）

1. 亮部提取 `W(L)`：none / hard / soft
2. 可分离高斯模糊 `B = K * W(L)`，截断核按窗口重新归一化（和为 1）
3. 加法合成 `out = clamp(L + gain * B)`

## 软膝与解析关系

软膝函数（C0 连续，t0 处 C1）：

```
W(L) = 0                      L <= t0
     = (L-t0)^2 / (t1-t0)     t0 < L < t1      t1 = t0 + δ
     = L - t0                 L >= t1
```

它逐点满足 `W(L) <= (L-t0)+`。设保护采样点 x 的二维截断核权重为 k_j，
支撑集为 S，则该点的抬高量是下限 t0 的**分段二次、连续、单调不增函数**：

```
e(x;t0) = gain * Σ_j k_j W_t0(L_j)
        = gain * [ Σ_{L_j>=t0+δ} k_j (L_j-t0)
                 + Σ_{t0<L_j<t0+δ} k_j (L_j-t0)^2/δ ]
```

单调性 → 给定容差 ε，满足全部保护点 `e <= ε` 的最小下限可由二分精确反解
（`solve_floor`，40 次迭代，收敛到浮点精度）。

二值/均匀高光的特殊情形有闭式解（令 p* 为落在高亮区的核权重和）：

- 线性段（A >= t0+δ）：`t0 = A - ε/(gain·p*)`
- 二次段（t0 < A < t1）：`t0 = A - sqrt(δ·ε/(gain·p*))`

### 一个被验证否掉的错误简化

不要写成 `B(x) <= M(x) - t0`（M 为无阈值模糊）再取 `t0 = M* - ε/gain`。
由 `(L-t0)+ >= L-t0` 只能推出 `K*(L-t0)+ >= M-t0`：当 M < t0 时右边为负，
根本不是上界。正确的上界 `B <= K*(L-t0)+` 是**邻域逐像素求和**，无法只用 M
表达。自测里保留了这个不等式的数值检查，防止退化回错误形式。

## 两阶段验证

```bash
cd validation && ./run.sh
```

参数：σ=20、截断半径 60（3σ，故意保留可见的尾部截断）、gain=1、ε=2 灰阶、δ=16。

- **阶段 A 合成图**：512×512 纯黑 + 一块 240 灰阶均匀高光，10 个暗部采样点。
- **阶段 B 实拍图**：astronaut（大片黑色太空 + 高亮航天服），每 64×64 格取最暗点，
  共 10 个真暗点（L 多为 0）。

每点记录三个数：独立二维核求和的解析抬高 `e_analytic`（与管线的可分离模糊
完全不同的代码路径）、管线实测 `e_measured`、未截断理想高斯核预测 `e_ideal`。

结果（`validation/out/report.txt`）：

| 检查 | 阶段 A | 阶段 B |
|---|---|---|
| max \|解析 − 实测\|，10 点 | 0.000000 | 0.000000 |
| 反解下限 t0 | 231.7380 | 213.6023 |
| 实测最大抬高 vs ε=2 | 2.0000 通过 | 2.0000 通过 |
| 无阈值基线最大抬高（原 bug） | 112.51 | 116.17 |
| 同下限硬阈值最大抬高 | 3.87 | 2.17 |
| 闭式 vs 二分 | 二次段闭式 231.7380，差 0 | — |

**对不上的归因规则与实测**：解析与实测 0 误差，说明下限计算无错；尾部截断的
影响用独立实验隔离——用理想核反解 t0_ideal 再喂给真实（截断）管线，超出 ε 的
部分纯粹来自缺失尾部，两阶段均为 +0.0100 灰阶（理想核窗外质量 0.496%，经重归一化
与软膝平方衰减后只剩 0.01 量级）。若未来出现解析/实测失配，先查核归一化与
边界处理（本实现 clamp-to-edge + 窗内重归一化），而不是怀疑解析式。

8 位量化后从 CLI 产出的 PGM 复核，暗部抬高仍 <= 2 个码值。

## CLI

```bash
./bloom process IN.ppm OUT.pgm -mode soft -t0 213.6 -t1 229.6 \
        -sigma 20 -radius 60 -gain 1 [-dumpblur b.pgm] [-dumppre p.pgm]
./bloom solve   IN.ppm PTS.txt -eps 2 -delta 16 -sigma 20 -radius 60 -gain 1
# PTS.txt: 每行 "x y"，即需要保护的暗部采样点
```
