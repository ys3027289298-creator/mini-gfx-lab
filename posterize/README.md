# posterize

感知均匀的海报化（posterize）量化。逐通道量化会让不同色相的断层落在不同位置，
这里改为在 CIELAB 的 L\* 轴上建等距格点，色相不参与量化。

- **等距量化**：`levels` 个格点，L\* 中心在 `(k+0.5)·100/levels`；每个像素取
  CIE76 感知距离最近的格点。中性色即最近 L\*，高饱和色在色域边界处按同色相
  降彩度，因此不会整块偏色。
- **抖动核按对比敏感度加权**：Bayer 有序抖动在最近的两个格点之间混合，混合
  概率按 Mannos–Sakrison 亮度 CSF × 亮度自适应归一化（参考条件 L\*=50、4×4 核、
  `viewing_ppd` 下为 1.0）。暗部与低频核获得更多抖动；抖动只选格点，不产生
  格点外的颜色。
- **参考比对**：对每个像素做穷举 CIE76 最近格点搜索得到参考图，再与抖动输出
  逐像素比较，输出最大/均方根 ΔE，同时输出参考图自身对原图的 ΔE。
- **参数校验**：色阶数 2..16、核尺寸 2/4/8、`amplitude` 0..1、`viewing_ppd` > 0，
  否则返回 -1。
- **关闭即恒等**：`enabled = 0` 时逐字节原样输出，即使其它字段非法也不参与校验。

```bash
make test
```

自检会报告形如：

```
max_delta_e=25.5482 rms_delta_e=8.6252 at=(0,36) band_pair_bound=25.6138
```
