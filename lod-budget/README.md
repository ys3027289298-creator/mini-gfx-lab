# lod-budget

多帧预算下的 LOD 全局最优选级，与单帧贪心选级对照。

## 三种策略

- **greedy（对照）**：只看当前帧，从最高 LOD 起按「误差增量 / 节省成本」
  逐个降级直到不超预算。短遮挡结束、预算回升后立即切回，无历史记忆。
- **rolling（主策略）**：把一帧内全部物体的 LOD 组合枚举为状态（5 物体 ×
  4 级 = 1024 态），在未来 10 帧的预测窗口上做动态规划，转移代价
  = 可见质量误差 + λ·切换次数，预算作为硬约束剪枝。滚动视界只提交窗口
  首帧决策；实际预算低于预测导致超支时回退到该帧的贪心可行解，并把预测
  偏差重置为 0（回退已确认是瞬时冲击，下一帧预测立即回到名义预算）。
- **oracle（锚点）**：全程实际预算已知的一次性 DP，给出真正的全局最优下界。

## 场景设计

- 每 10 帧一次全物体同步的 2 帧短遮挡：贪心整批降级再升回（每轮
  2×N_OBJ 次切换），DP 看穿遮挡保持级别不动；另有错相的单帧遮挡噪声。
- 普通帧预算恒为名义值 300（全部物体走 L1 需 275，可行），预测完全可信；
  第 7/18/29/40 帧骤降到 ~100（仍高于最低可行成本 75），EMA 预测必然
  高估，精确触发 4 次回退，无任何帧超预算。

## 验收口径（程序内置断言，失败返回非零）

1. `budget_never_exceeded`：三种策略任何帧都不超预算；
2. `cost_not_worse_than_greedy`：总代价（质量误差 + λ·切换）不高于贪心；
3. `switches_30pct_less`：切换次数 ≤ 贪心的 70%；
4. 逐帧输出两策略的级别、资源占用、质量误差、切换数与逐帧总代价。
