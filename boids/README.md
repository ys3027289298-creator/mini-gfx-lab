# boids

Reynolds 群体行为（flocking）：分离 / 对齐 / 聚合三条规则，空间哈希加速邻域查询。
1000 个粒子在 750×750 的环面（torus）世界里运动，参数扫描下呈现三种可复现的
涌现状态。

## 构建与自测

```bash
make test
```

自测包含四部分：

1. **邻域查询正确性** — 空间哈希与暴力 O(N²) 对每个 boid 的邻居计数逐一比对，零误差。
2. **积分一致性** — 哈希与暴力两条路径各推进一步，位置/速度最大偏差 ~1e-6（含噪声开/关两种）。
3. **性能预算** — 1000 粒子 300 帧计时，并统计邻居距离测试次数。
4. **参数扫描** — 三组预设跑出三种状态，对极化度 / 局域密度 / 局部涡旋度做断言。

可用 `BOIDS_SEED=<n>` 换初始随机种子验证鲁棒性；也可手动调参：

```bash
./boids <sep> <ali> <coh> <fmax> [noise] [coh_sat] [s]   # s = 打印每秒指标序列
BOIDS_SEED=7 ./boids 80 6 0.5 500 0 10
```

## 三条规则

| 规则 | 实现 | 量纲 |
|---|---|---|
| 分离 separation | 邻域内（`sep_r` 内）反距离推力的平均方向 | u/s² |
| 对齐 alignment | 邻居平均速度 − 自身速度（同时匹配航向与速率） | 1/s |
| 聚合 cohesion | 指向邻居质心的饱和弹簧：力幅随距离增长，到 `coh_sat` 封顶 | 1/s² |

合力钳制在 `max_force`，速率钳制在 `[min_speed, max_speed]`。聚合用饱和弹簧而非
纯单位方向——纯方向力在团内部互相抵消、无法持续压缩；饱和后近核只转向不压死，
为涡旋（milling）保留轨道运动。

## 空间哈希

- 格子边长 = 感知半径 `R_NEIGH = 25`，世界划成 30×30 格。
- 计数排序（counting sort）一帧建一次表：两次线性扫描，无动态分配。
- 每个 boid 只查自身所在格 + 3×3 邻格（环面取模）。
- 采用 Jacobi 更新：先从当前位置的冻结快照算完全部力，再统一积分，
  因此与暴力路径语义完全一致、可逐位比对。

## 三种涌现状态

扫描跑 2400 帧（40 秒），指标取最后 90 帧（1.5 秒）的稳态平均。下表为
20 个随机种子下的典型区间：

| 预设 | 主导规则 | pol 极化度 | dens 平均邻居数 | mill 局部涡旋 |
|---|---|---|---|---|
| gas（弥散气态） | 强分离 + 强噪声 | ~0.01–0.04 | ~4（均匀基线） | 无序 |
| mill（聚团涡旋） | 强聚合 + 弱对齐 | < 0.40 | 19–30（gas 的 5–7 倍） | 最高 |
| flock（定向流动） | 强对齐 + 对称破缺噪声 | > 0.6（多在 0.8 以上） | 7–12 | ≈ 0 |

flock 预设带低幅噪声：群体的「定向流」与「静态团」是两个竞争吸引子，纯确定性
动力学下部分初始构型会卡在静态团；与世界种子绑定的确定性噪声提供对称破缺，把
系统稳定推入定向流，同时不破坏哈希/暴力两条路径的逐位一致性（噪声是
`(index, frame, seed)` 的纯函数）。

指标定义：

- `pol`：归一化平均速度，0 = 完全无序，1 = 全体同向。
- `dens`：感知半径内的平均邻居数，直接反映局域密度。
- `mill`：每个 boid 绕自身邻居质心的局部角动量（对环面拓扑和平移稳健），
  至少 6 个邻居才计入，避免稀疏区噪声。

## 性能（参考机器，`-O2`）

- 单帧平均 ~0.09 ms、最大 ~0.3 ms，预算 3 ms。
- 每帧邻居距离测试：哈希约 1.7 万次 vs 暴力 99.9 万次，**加速 43–59 倍**
  （参数扫描中最密集的情形也 > 42 倍，满足「少一个数量级」即 ≥10× 的要求）。
- 自测覆盖 20 个随机种子（`BOIDS_SEED` 可复现），三种状态的断言全部通过。
