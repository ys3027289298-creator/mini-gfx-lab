# streammap

超大地图的分块流式加载。整张图存在磁盘上的 tile store 里，内存中只保留固定数量的 LRU 块。

- 按块索引加载/卸载（`Cache`、`cache_unload`），块缺失时按需调入，满了按 LRU 逐出。
- 访问器统一按绝对世界坐标取格，跨块的自动拼接掩码读的是世界而不是当前块，块边界无缝。
- 矩形查询先裁剪到世界范围再按块求和，越界/反向/跨界输入都不会打开世界外的块，也不会重复计数。
- 流式与整图加载逐格对比（tile 值和 4 邻接 variant），在缓存容量 0、1、整图全驻留下结果与哈希完全一致。
- 峰值内存只由驻留块数决定，与地图大小无关。
