# hrtf

头相关冲激响应（HRIR）数据集加载、方位角/仰角双线性插值、逐块双耳卷积。

```bash
make test
```

## 数据集格式

纯文本，每方向两行（左耳、右耳），`#` 起注释：

```
@hrtf 1
@rate 48000
@taps 80
@elev -40 -20 0 20 40
@az 0 15 30 ... 345
<az> <el> L0 L1 ... L79
<az> <el> R0 R1 ... R79
```

- 方位角 0=正前，+90=右耳，负值/超过 360 自动回绕。
- `@az`/`@elev` 给出插值网格；省略则由文件中出现的角度推导。
- 每个网格节点都必须给出。缺节点、重复节点、左右耳角度不一致、行长度不符都直接报错，
  不做补零猜测。

## 处理链

1. 加载后每对 HRIR 归一到同一 RMS，避免网格节点间响度跳变。
2. 默认 8 kHz 零相位低通（前后各滤一遍）。插值两个起始时刻不同的响应时，
   高频尾巴会梳状相消；带限后插值增益偏差显著变小，且起始时刻（ITD）不动。
3. 双线性插值：方位角按 0/360 环绕取相邻两列，仰角取相邻两行，四点加权。
   超出仰角网格时钳位到端点。
4. 卷积使用整条 HRIR（含数据自带的延迟），不额外施加 ITD 平移 —— 这正是
   节点边界处起始时间连续的原因。

## 自测关注点

- **插值收益**：10 个网格外方向，与未带限的真实模型响应比较。
  插值平均相对误差 0.34，最近邻 0.62，约 **1.85×**；且每个点都优于最近邻。
- **无可闻不连续**：在相邻节点中点两侧各 1e-3 度取样，插值跳变 ~2.5e-4
  （数值零），最近邻跳变 1.36。0/360 接缝与普通内部边界一致。
- **平滑扫描**：角步长减半，响应变化量同步减半（0.116 → 0.0587 → 0.0295），
  即变化完全由转角决定，没有叠加固定跳变。
- **卷积正确性**：逐样本输出与直接求和参考一致（相对误差 1.9e-7）；
  分块流式调用与一次性调用逐位一致。
- **单帧预算**：128×9 全尺寸网格、每块换方向的压力测试下，
  插值路径平均 0.00006 ms/帧、最差 0.0005 ms/帧，远低于 3 ms。
  `frame_budget_under_3ms` 是显式断言。

## 接口

```c
int  hrtf_load(Hrtf*, const char* path, float lp_fc);
void hrtf_hrir_bilinear(const Hrtf*, float az, float el, float* hl, float* hr);
void hrtf_hrir_nearest (const Hrtf*, float az, float el, float* hl, float* hr);
void hrtf_render_block(const Hrtf*, int interp, float az, float el,
                       const float* mono, int frames, float* out,
                       Convolver* cl, Convolver* cr);
```

`hrtf_render_block` 每次调用处理一个固定方向的音频块；方向由调用方在块之间更新。
卷积器历史跨调用保留，所以把流拆成任意块长与一次调用结果相同。
