# density

按屏幕占比分配的粒子预算：相机拉远时不再把近景的固定每格配额原样套到
整片可见格网上，而是按每格投影像素面积重新分配总发射预算。

## 模型

- **比例系数（闭式解）**：参考视口（60° 垂直 fov、1080p）下 `K = 1`，
  任意视口下
  `K(fov, H) = (H / H₀)² · (tan(fov₀/2) / tan(fov/2))²`，
  深度项在面积比中约掉，系数只由视场和分辨率决定。
- **双焦段密度曲线**：长焦段（fov ≤ 60°）权重取 `(K / depth²)^1.0`，
  保持恒定屏幕密度；短焦/广角段取指数 `0.6`，让密度随面积缓慢稀释，
  避免远景粒子成片消失。
- **配额求解**：可见格按权重分每帧总预算，最大余数法补齐取整误差，
  总投放恒等于预算。关闭开关或触发回退时改为可见格均匀分配。
- **峰值记录**：长焦、短焦各自维护单格存活峰值，只增不减，
  开关切换期间持续记录、不清零。
- **极端长焦压测与回退**：fov 收到最窄并跑到稳态，若单格峰值压不住
  `cell_cap`，置回退标志并重新验证均匀分配能否把峰值压回 cap 内。
