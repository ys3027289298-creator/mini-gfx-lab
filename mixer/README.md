# mixer

多总线音频混音：每总线增益、侧链闪避（sidechain ducking）、软削波，以及
增益参数自动化。所有缓冲区为交错立体声（interleaved stereo）。

`make test` 跑自检（33 项检查，全过返回 0）。

## 增益自动化

每条总线（sfx / music / voice）的增益都可以挂一条断点曲线，曲线由若干
片段组成，片段类型：

- `AUTO_LINEAR`：增益随时间线性变化；
- `AUTO_EXP`：增益随时间指数变化（要求两端增益均 > 0，插入时校验拒绝 0/负值）。

核心 API（见 `src/mixer.c`）：

- `auto_init / auto_append`：构建曲线，追加片段；片段在追加时一次性预计算
  斜率（线性斜率 / log 域指数斜率），热路径不再调用 `log`。
- `auto_eval`：任意时刻的精确曲线值，范围外保持端点值。
- `auto_ramp_from_now`：运行时换曲线，以旧曲线在该时刻的增益为新片段起点，
  因此切换瞬间不产生阶跃。
- `mix(...)`：每个处理块（128 帧）开始时用精确值进入当前片段，之后逐样本
  每总线仅一次乘加前进（线性用加法 ramp，指数在 log 域用乘法 ramp）；
  块/片段边界总是用精确曲线值重新锚定，误差不会跨块累积。

### 设计约束如何满足

- **与逐样本手算曲线一致**：块内两端点用闭式 `seg_val` 精确求值，块内逐样本
  插值；自检把融合混音路径、逐样本 `auto_eval`、独立参考实现 `auto_render`
  三路逐样本比对（含 128/37/16 帧不同块长、线性+指数拼接、超段长保持）。
- **切换无阶跃**：`auto_ramp_from_now` 从当前增益起 ramp；自检同时验证参考
  路径与融合热路径在切换块的首个样本等于旧曲线值。
- **开销 ≤ 混音本身的 20%**：实测（参考周期计数器 `rdtscp`，非 x86 回退到
  单调纳秒；多次取最小值）约 **3%–9%**。指数段的逐样本 log 增量极小，用
  4 阶泰勒近似（`exp_step`），遇到异常陡峭的短片段自动回退标准 `expf`。
