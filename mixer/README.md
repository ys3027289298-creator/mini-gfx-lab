# mixer

## 三段均衡

总线混音后、软限幅前串接一个三段 EQ（低/中/高，增益单位 dB，0 dB 为
直通）。

- 分频：两级 Linkwitz-Riley 4 阶交叉滤波（默认 250 Hz / 4 kHz），每级由
  两个 Q=1/√2 的 Butterworth biquad 级联而成；低交叉先把信号切成低频与
  高频，高交叉再把高频切成中频与高频。
- LR4 满足 |LP|²+|HP|²=1 且 LP+HP 为全通，三段 0 dB 时直接旁路滤波器
  算术，输出与旧路径**逐样本一致**（`memcmp` 校验，含分块与闪避场景）。
- 全程无任何信号取反支路，各通带内极性与输入同相，不会翻转相位。
- 交叉频率与采样率可通过 `eq_set_crossovers` 重新配置（要求
  0 < flow < fhigh < 奈奎斯特），重配会清零滤波器状态。
- 自检对四组共 12 个频点、4 组增益设置，比较实测稳态响应与由实际系数
  算出的解析传递函数，幅度误差上限约 0.0002 dB（要求 < 0.5 dB）。
