# mixer

`make test` 跑自检。

## 总线混音

三总线（sfx/music/voice）混音、侧链闪避（voice 触发时压低 sfx）、软限幅输出。

## 三段动态处理（`Multiband`）

单段压缩对整段频谱施加同一个增益，低频一过阈值就把中高频一起压平。
`Multiband` 把信号分成低/中/高三段，各自独立压缩后再合成：

- **分频器**：Linkwitz-Riley 4 阶（每臂两个 Butterworth 二阶 biquad 级联），
  树状拓扑，交叉频率 350 Hz / 3000 Hz（48 kHz）。LR4 互补对之和恒等于
  二阶全通，低频臂再补一个同频全通做相位匹配，因此
  `low + mid + high = AP2(fc1)·AP2(fc2)`，幅频恒为 1。
- **每段独立参数**：`threshold_db`、`ratio`、attack/release、手动 makeup，
  6 dB 软膝，立体声联动峰值检波（一阶 attack/release 平滑）。
- **增益补偿**：`mb_calibrate()` 用参考信号实测每段压缩前后 RMS，自动 makeup
  恢复段内电平；另有 `global_makeup_db` 全局微调。
- **延迟**：全因果 IIR、无 look-ahead，算法延迟 0 样本；仅分频器群延迟，
  峰值 1.70 ms（225 Hz 处），交叉点处 1.44 ms / 0.17 ms，均 < 2 ms。

### 自检指标（48 kHz 实测）

| 指标 | 结果 | 要求 |
|---|---|---|
| 交叉处频响最大凹陷 | 0.000093 dB（解析）/ 0.00015 dB（时域正弦实测） | < 1 dB |
| 交叉点低/高通相位差 | < 1e-3 rad，全频段无相位跳变 | 无相位跳变 |
| 最大群延迟 | 1.70 ms | ≤ 2 ms |
| bypass 宽带电平差 | 0.0006 dB | 透明 |
| 段间串扰（只驱动低频） | 中 −51.9 dB / 高 −87.6 dB | 段独立 |

### 单段 vs 三段频谱对比（三音信号 80 Hz / 1 kHz / 8 kHz，dBFS）

| 段 | 干声 | 单段压缩 | 三段压缩 | 单段增益衰减 | 三段增益衰减 |
|---|---|---|---|---|---|
| 低 | −9.06 | −16.67 | −9.07 | 7.62 dB | 0.01 dB |
| 中 | −15.28 | −22.90 | −15.28 | 7.61 dB | 0.00 dB |
| 高 | −21.55 | −29.16 | −21.55 | 7.61 dB | 0.00 dB |

单段压缩把三段均匀压掉 7.6 dB（频谱整体被压扁）；三段压缩只作用于
真正过阈值的段，自动 makeup 后各段电平恢复到 ±0.01 dB 以内。
