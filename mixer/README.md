# mixer

`make test` 跑自检。

多总线混音（每总线增益、侧链闪避、软削波），并支持各源不同采样率：

- 多相滤波重采样：Kaiser 窗 sinc 原型（32 抽头、128 相位表 + 线性相位插值），
  按源采样率分别转换到 `Mixer.bus_rate`；同采样率走恒等直通。
- 每源独立的相位累加器（double）与历史延迟线，跨数据块相位连续，
  分块处理与整块处理位级一致。
- 切换源/总线采样率时保留历史并做 32 帧交叉淡变，不产生爆音。
- 滤波器表按（输入率，输出率）缓存共享；每帧固定抽头数，转换开销与源数线性。
- 自检含与 double 精度直接求值参考的误差比对（8 组采样率对，均 < -60 dB）。
