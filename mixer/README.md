# mixer

多总线（sfx / music / voice）立体声混音，提供两种限幅拓扑，可直接对照：

- **硬限幅 `mix_hard`**：零延迟峰值削波，超过阈值（±1.0）的样本直接削平。
- **前瞻限幅 `mix_la`**：按 5 ms 前瞻窗口预测峰值，用窗口运行最小值 +
  attack/release 单极平滑（释放时间可配，默认 100 ms）提前压低增益，并把信号
  延迟一个窗口使增益与样本对齐。侧链触发（人声总线能量超过阈值）时改为按总线
  联动分配衰减：人声总线优先，衰减被限制在 1 dB 以内，其余压到 sfx/music 上。

两种拓扑的输出峰值都不超过阈值。

`make test` 跑自检，打印逐项 `name=0/1`，并给出对照数据：峰值、THD（1 kHz
正弦、1.5 倍驱动，复 DFT 测 2–5 次谐波）、算法延迟，以及侧链触发时人声总线的
实际衰减（dB）。
