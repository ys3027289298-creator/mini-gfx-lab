# busgraph

数据驱动的信号总线图，替代 `mixer/` 里写死的三总线结构。加一路发送/返回或
侧链只改拓扑配置，不再改处理代码。

## 模型

- **节点**（`BgNodeCfg`）
  - `BG_SOURCE`：外部立体声输入，带输入增益；
  - `BG_BUS`：每块清零、对入边求和的总线；
  - `BG_DELAY`：带固有延迟（帧数）的返回节点；
  - `BG_DUCK`：控制节点，由控制边的平均能量产出一个标量增益；
  - `BG_MASTER`：唯一输出，求和后软限幅。
- **连线**（`BgEdgeCfg`）：`BG_AUDIO` 音频扇出（单边增益，可一发多收即
  send/return）或 `BG_CONTROL` 控制边（不参与音频，仅驱动 duck 侧链）。

## 执行与校验

- `bg_build()` 用 Kahn 算法按声明序做拓扑排序；无法入度归零的节点判定为环，
  返回 -1 并在 `err` 中列出环上节点 id。同时校验重复 id、未知节点、自环、
  缺失 master、控制边接法、延迟越界等。
- `bg_execute()` 每个 block（128 帧，交错立体声）按拓扑序跑一遍。
- **延迟自动对齐（PDC）**：按拓扑序求每个节点的最深固有延迟 `D(n)`
  （从任意 source 到该节点输出的最长延迟，节点自身延迟在入边处只计一次），
  边 `u->v` 的补偿延迟为 `D(v) - L(v) - D(u)`，由该边私有环形缓冲实现；
  零延迟边直通、不做任何缓冲，因此无延迟路径与旧 `mixer` 逐位一致。
- 重建（拓扑）与单块执行分别用 `clock_gettime` 计时，自检里分别打印
  `rebuild_*_avg_ns` 与 `execute_per_block_avg_ns`。

## 自检

`make test` 跑自检，覆盖：

- 与 `mixer/` 硬编码实现逐样本 `memcmp` 完全一致（固定用例 + 64 块随机流）；
- 成环、未知节点、重复 id、控制边误接、缺 master 均被拒绝并报错；
- 新增一条 send/return 总线无需改处理代码，干湿两路在同一帧对齐；
- 固有延迟不同的两条总线自动对齐，含跨 block 边界；
- 重建耗时与执行耗时分开上报。
