# pyramid

大图分块处理用的图像金字塔：逐级生成、按区域查询对应级别，任何一块都等价于对全图做完整
处理，但只支付实际访问像素的代价。

```bash
make test
```

## 模型

- 第 k 级单元 `(i,j)` 保存底图矩形
  `[i·2^k,(i+1)·2^k) × [j·2^k,(j+1)·2^k)`（裁剪到图像边界）内全部像素的
  **整数和**（`long long`，无浮点误差）。
- 每一级的单元都构成底图的一个划分，因此逐级做 2×2 归约与从底图直接重算该级
  **逐单元相同**；奇数边长靠 ceil 划分处理，边界单元是 1×2 / 2×1 / 1×1 而不是完整 2×2。
- 级别惰性分配：`pyramid_init` 只分配底图（第 0 级），`pyramid_ensure_level`
  每次只长出一级，内存按需增长。

## API

| 函数 | 作用 |
|---|---|
| `pyramid_init / pyramid_free` | 只分配第 0 级 / 释放已分配级别 |
| `pyramid_build_next` | 由上一级精确生成一级（2×2 求和） |
| `pyramid_ensure_level` | 逐级生成到指定级，已存在则直接返回 |
| `pyramid_pick_level` | 按区域短边与目标单元数选最粗可用级 |
| `pyramid_query` | 区域（底图坐标）吸附到级网格，输出覆盖该区域的粗级单元 |

## 自测覆盖

1. `level_by_level_exact`：53×37（含奇数边）每一级与从底图直接重算的结果 `memcmp` 一致，
   且内存计数随逐级生成精确增长。
2. `region_query_exact`：60 组随机级别/矩形（含越界、空矩形）区域查询，与全图重算基线
   `naive_query` 逐单元一致。
3. `query_ops_eq_output_cells` / `query_cost_linear_in_pixels`：查询读单元数恰为输出单元数；
   区域边长翻倍、耗时变 4 倍；256→2048 放大图像，同一区域查询开销不变，而朴素全图处理
   随 N² 增长。
4. `pick_level_invariant`：选出的级保证区域短边至少有 target 个单元，且再粗一级就不满足。

## 内存上界（与级数 L 的关系）

设底图 W×H，每单元 8 字节：

- 精确式：`M(L) = 8 · Σ_{k=0}^{L-1} ⌈W/2^k⌉·⌈H/2^k⌉`
- 2 的幂尺寸：几何级数 `M(L) = 8WH·(4/3)·(1 − 4^(−L))`，**极限 < 底图内存的 4/3**。
- 一般尺寸（含 ceil 项）：
  `M(L) ≤ 8·(WH·(4/3)(1−4^(−L)) + (W+H)·2(1−2^(−L)) + L)`
- 级数本身为 `L_max = ⌈log2(max(W,H))⌉ + 1`。
