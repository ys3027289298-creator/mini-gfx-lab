# mini-spatial-audio

双耳定位：方位角→ITD/IID、反距离衰减、多声源软限幅混音。
ITD 用 48 tap 加窗 sinc 分数延迟线（FDL）实现亚采样精度，固定群延迟 23.5 采样 + 32 采样整体延迟（双耳一致，不影响相对 ITD）。

```bash
make test
```

## 分数延迟测量

`make test` 末尾输出三项测量，任一不达标退出码非零：

- **M1 亚采样延迟误差**：200–1000 Hz 五音相位斜率拟合群延迟，与指令延迟比较，要求 < 1/20 采样。实测最大 9.4e-07 采样。
- **M2 通带相位偏差**：逐频点最小二乘测相，与解析全通相位响应 H(e^jω)=e^{-jωD} 比较，通带 50 Hz–21.6 kHz（0.9π）内要求 < 3°。实测最大 0.116°（frac 扫描 ±0.45）；附带幅度平坦度数据（≤0.04 dB，近全通）。
- **M3 连续变参爆音**：延迟参数逐采样连续变化（1 s / 0.1 s / 10 ms 线性扫描、2 Hz 正弦调制），检查输出相邻采样跳变不越正弦导数上限（含多普勒放宽）。实测各场景比值 ≤ 1.0，越界点 0。
