# mini-spatial-audio

双耳定位：方位角→ITD/IID、反距离衰减、多声源软限幅混音。

房间混响：每房间一条单位能量冲激响应（IR），卷积渲染 + 换房间等功率交叉淡入。

## 换房间交叉淡入

- **按时间交叉**：淡入期间新旧房间的 IR 并行卷积，输出按逐样本增益相加；
  淡入时长以采样数给定（`reverb_set_room(rv, room, fade_frames)`），支持分块处理。
- **曲线（等功率）**：归一化进度 `u∈[0,1]`，旧房间 `g_o=cos(πu/2)`、
  新房间 `g_i=sin(πu/2)`，全程 `g_o²+g_i²=1`，两条不相关房间响应的合成功率恒定；
  端点斜率为 0，与稳态斜率连续，声音只在增益恰为 0 时切入/切出，不出爆音。
  中途再次换房会快照当前增益后重定向，不断音。
- **资源释放**：房间带引用计数，淡入开始对新房间 `acquire`，旧房间的引用
  由其卷积声轨持有直到淡入结束才 `release`；计数归零才释放 IR 内存与池槽位，
  可被后续房间复用。淡入结束后输出与新房间单独卷积逐样本一致。
