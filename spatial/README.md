# mini-spatial-audio

双耳定位：方位角→ITD/IID、反距离衰减、多声源软限幅混音，并对声源做空间分组，
避免听者每次移动都把所有声源重算一遍。

```bash
make test
```

## 空间分组

- 声源按世界坐标分进均匀 xz 网格桶（8 m 一格，8×8 桶），桶用链表组织，O(1) 格归属。
- 听者按所在格的**格中心量化**，于是几何在一个格内恒定：
  - 听者静止或在同一格内移动 → 命中缓存，**零重算**；
  - 跨格或转向 → 对全部桶内声源做一次**精确**全量重算（按源顺序、逐桶遍历）。
- 为什么不是"只重算听者附近的桶"：平移会改变**每个**声源相对听者的方位与距离，
  远场声源同样变化（实测 ITD 会变），局部桶更新只能得到近似结果，无法逐样本一致。
  格量化让"格内复用"成为精确缓存而非近似，这是同时满足省算与 bit-exact 的关键。
- flat 参考路径采用相同的格量化、相同的 per-source 数学和相同的源顺序，
  因此分组路径与逐个重算 **bit-identical**（随机 80 帧、含移动/转向/声源迁移，`memcmp` 校验）。

## 自测输出

- `bitexact_all_frames=1`：分组与逐源重算逐样本一致；
- `incell_or_idle_no_recalc=1`：格内移动/静止不重算；
- `recalc_count_matches_cell_dirty_rule=1`：重算数严格符合脏格规则；
- 基准对照（512 声源、120 帧、256 帧/块）给出 `flat_recalc` vs `grp_recalc`、
  节省比例，以及分组记账开销占总耗时比例（预算 20%，实测约 0.02%）。
