# mini-spatial-audio

双耳定位：方位角→ITD/IID、反距离衰减、多声源软限幅混音。

5.1 下混（影院场景）：

- 六声道交织输出 L / R / C / LFE / SL / SR，扬声器布局按 ITU-R BS.775（L/R ±30°、SL/SR ±110°）
- 解析声像权重 `w_i = max(0, cos(方位夹角))`，能量归一化 `g_i = w_i/√Σw²`，恒有 `Σg_i² = 1`
- 中心声道按前后权重生成：`w_C = max(0, cos az)`，侧方（90°）与后方声源 C 严格为 0
- 80 Hz 一阶互补分频：低频合并进 LFE，高频进五个全频声道，`low + high = x` 可完全重构
- 验收：六朝向（每 60°）能量分布对解析权重误差 < 5%、总能量守恒、单帧（8 声源 × 512 帧）< 3 ms
