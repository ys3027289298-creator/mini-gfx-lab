# mini-spatial-audio

双耳定位：方位角→ITD/IID、反距离衰减、多声源软限幅混音。

每帧声源预算裁剪（`render_budget`）：

- 按听者侧功率（距离衰减 × 声源能量）排序，只对前 N 个声源做完整空间化，同分按索引稳定决胜
- 被裁声源不静音：功率按非相干叠加汇入居中的 diffuse bed 做能量补偿
- 成员关系带滞回（在位者获得 HYST_TAU 加权，边界抖动不反复进出）
- 每条声线在空间路径与 diffuse 路径之间等功率交叉淡化，边界抖动不产生台阶/爆音
- 无分配、无墙钟状态、固定决胜规则，N 缩小与放大的结果逐字节确定
