# mini-gfx-lab

游戏与图形方向的小项目集合，每个子目录是一个可独立构建、可测试的小库。

| 目录 | 内容 |
|---|---|
| `navgrid/` | 8 方向 A*、禁止切角、视线平滑、增量重规划实验台 |
| `spatial/` | 双耳定位 ITD/IID、距离衰减、软限幅混音；5.1 下混（余弦解析声像、中心前后权重、LFE 分频） |
| `particle/` | 固定容量粒子池、每帧配额、发射器优先级 |
| `lod/` | 屏幕误差 LOD 选择与迟滞 |
