# lightmap

按半球采样把光照烘焙成 SH-L2 辐照度，打包为 fp16 贴图，运行时按法线双线性采样。

- `bake`：每个 texel 在球面上分层采样，投影到 9 个 SH 系数 × 3 通道；
  每个 texel 再用 `box × box` 个子位置做足迹平均，避免贴图接缝处走样。
- `sample`：周期网格上双线性插值系数，再按 `sum A_k * L_k * Y_k(n)` 求出
  辐照度/π，因此相邻块共享边缘时数值连续、不跳变。
- 已知取舍：SH-L2 对 delta 光的背光法线残余约 0.03（占峰值 3%），有界且非负；
  若换用硬面光源会出现振铃，需要 clamp 后再参与光照。

`make test` 跑自检：自检会打印烘焙 texel 数、每 texel 采样数、总采样数与耗时，
并把运行时采样与逐像素直接积分对比，报告 `texel_err_max` / `filter_err_max`，
以及接缝步长与内部步长对比、接缝检测的负向对照（clamp 采样必须被检出）。
