# fsc

频率相关侧链压缩（frequency-selective sidechain）。

普通侧链对整条总线做统一增益衰减：低频触发一来，鼓声和贝斯连同中高频
一起被压下去，声音发闷。本模块先把目标信号和触发（key）信号用同一组
Linkwitz–Riley 4 阶分频器切成若干频段，每个频段只按**自己频段内**的触发
包络计算增益，只压被触发的频段，再把各频段加回去。分频频率通过配置传入
（2–4 个频段，1–3 个交叉频率）。

`make test` 跑自检。

## 算法

1. 每个频段是一条 LR4 路径：低通×2（低频段）、高通×2（高频段）或
   高通×2 再低通×2（中间频段）；每级 LR2 是 Q=0.5 的 Butterworth biquad
   （DF2 转置）。目标信号与 key 信号走各自独立的滤波器状态。
2. key 频段取绝对值，经攻击/释放一阶包络跟随器（系数
   `1 - exp(-1/(fs·τ))`）。
3. 包络超过阈值时增益 `g = (thresh/env)^(1-1/ratio)`，否则增益恒为
   字面量 `1.0`（空闲频段不做任何乘法）。
4. 目标频段乘上自己的增益后逐频段求和输出。

逐样本流式处理、无前瞻、无重采样，输入时间基保持原样；`target`、`key`
缓冲区只读，从不写回。

## 三套独立实现与误差验证

同一个算法在 `src/fsc.c` 里有三份实现：

| 实现 | 精度 | 结构 |
|---|---|---|
| `fsc_process`（产品路径） | float | 逐样本流式，状态驻留，可任意分块调用 |
| `ref_process_f`（逐频段手工处理） | float | 独立编写的系数/biquad 代码，频段主循环，整段缓冲 |
| `gt_process_d`（真值） | double | 与手工路径同构，并记录逐样本中间量轨迹 |

- 两条 float 路径虽然独立编写，但操作顺序刻意保持一致，因此输出必须
  **逐样本位相同**（`manual_matches_streaming`，含任意分块调用的
  `block_split_matches`）。构建加 `-ffp-contract=off`，避免 FMA 收缩在
  不同调用点产生差异。
- double 真值给出 float 舍入的实际最大偏差；同时 `error_bound` 沿 double
  轨迹做**逐样本最坏情形误差传播**，给出解析上界：每个 biquad 满足
  `|e[n]| ≤ ρ|e[n−1]| + 16u·M[n]`（8 次舍入 + 5 个存储系数，M 为该级
  实际输入幅度），包络一阶滤波器和阈值增益按各自的 Lipschitz 常数传播，
  阈值以下增益恒为 1、无误差项。自检要求实测偏差处处不超过上界。
- 压力测试（3 种分频布局 × 白噪/脉冲/门控音调/混合信号 共 12 组）下上界
  均成立，最坏余量约 1.4×；正弦测试用例余量约 10×。上界是严格的，余量
  大小随信号对滤波器极点的激励程度变化。

## 自检覆盖

- 选择性：低频触发只压低频段、高频触发只压高频段（直接断言同一次运行的
  逐频段增益轨迹与包络，而不是相减两次独立运行——后者会把滤波器初态
  瞬态泄漏进差值）
- 重构恒等式：无触发时各频段信号逐样本加回等于输出
- 配置校验：频段数、交叉频率范围与单调性、ratio、时间常数、空指针
- 立体声包装等于两条独立单声道路径
- 输入序列字节级不变（双校验和）

## 物理限制（非实现缺陷）

LR4 分频只有 24 dB/oct，紧邻交叉频率的内容会同时出现在两个频段。若触发
音本身落在过渡带内，相邻频段会被连带触发——这是分频斜率的物理限制，
靠提高频段数或把交叉点挪离触发源频率解决，代码内无法消除。测试用例的
音调都距交叉点 ≥2.4 倍频程，使过渡带泄漏低于 1e-3。
