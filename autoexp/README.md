# autoexp

自动曝光统计链：分区域直方图 → 排除过曝像素 → 分位数测光 → 区域间平滑 →
按有效像素数加权聚合 → 升/降分离的时域适应 + 每帧步进限速。

区域网格默认 16×9；直方图 64 档（8-bit luma 每 4 级一档）。测光一遍扫描、
每个像素恰好访问一次，因此开销与像素数线性。

自检内容：

- 每个区域的直方图 / 有效像素数 / 过曝数 / 分位数逐项与逐像素朴素统计对齐，
  全局直方图、分位数、均值同样对齐（均值误差 ≤ 半个档宽）
- 纯色图各区域 EV 完全一致、区域间平滑在均匀场上恒等
- 过曝区域从测光中被排除（半幅过曝与不过曝得到相同目标）；整帧过曝时保持原目标
- 场景突变：报告跳变次数、最大单帧步进，以及收敛到剩余量 50%/90%/容差的帧数与毫秒数；
  与同样场景下的“硬切”参考（无时域平滑）对比——后者每次突变计一次跳变
- 统计开销 ns/px，覆盖 0.15–2.4 Mpx，波动 ≤ 2×
