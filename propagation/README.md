# propagation

离线预计算声源传播场：把到达时间与衰减烘焙到网格上一次，运行时按听者位置插值，
替换「每帧对整张网格重算传播」的做法。

- 模型：矩形房间镜像源法（直达 + 最多 3 阶墙面反射）。
  到达时间取能量加权平均，衰减取 RMS 幅值；距离衰减 `1/(1+0.2d)` 在源点也有界。
- 默认网格 16 m × 12 m、间距 0.025 m（641×481 节点），双线性插值。
- 插值在网格节点处精确还原烘焙值，在单元边界上 C0 连续，网格外坐标夹取到边界。

```bash
make test
```

自检输出：

| 指标 | 说明 |
|---|---|
| `bake_ms` / `bake_bytes` | 预计算耗时与内存（每节点 2 个 float） |
| `max_time_err_ms` / `max_gain_err` | 与逐点直接求值的最大误差（容差 0.02 ms / 2e-3） |
| `refinement_*` | 网格减半后误差按 ~4× 收敛，说明误差受分辨率限制 |
| `edge_*_jump` | 跨单元边界的跳变量；随探测偏移收缩，作为反例的逐格最近邻不收缩 |
| `frame_speedup` / `break_even_frames` | 整场逐帧重算 vs 预计算；预计算约 1 帧即回本 |
| `per_query_speedup` | 单次查询 vs 单次直接求值 |

**限制**：声源处到达时间场是锥面（`t = d/c` 的梯度在源点不连续），
任何固定网格在源点邻域都无法用双线性精确重建，误差为 O(h)。
因此容差声明适用于距声源 **2 个单元（0.05 m）之外**；该区域内的
最大误差（`near_source_max_err_ms`）单独报告而不计入容差判定。
实际听者不会与声源重合，这一邻域不具物理意义。
需要覆盖更近处可加密该区域网格，误差按 O(h²) 下降。
