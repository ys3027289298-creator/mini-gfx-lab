## 像素对齐（glyph_snap）

小字号笔位/基线落在半像素时按基线吸附到整像素，解决发虚问题。

- `SnapConfig`：`max_offset`（所有调整量的硬上限，像素）、`small_px`（该高度及以下启用横笔画对齐）、`max_width_delta`（允许的宽度变化，整格）。
- 笔位按四舍五入取整；最近网格超过 `max_offset` 时返回 `SNAP_E_CAP`，不钳制、不硬吸。
- 小字号下额外计算亚像素轮廓修正量 `hy`，让横笔画边缘落上像素格：整数格平移不改变边缘的小数部分，所以这一步不能只靠平移。候选修正量按各横边到网格线的总距离打分，并同样受 `max_offset` 钳制。
- 宽度守卫：强制覆盖所有触及像素格的跨度与取整后宽度相差超过 `max_width_delta`（默认 1 格）时返回 `SNAP_E_WIDTH`，报错而不是硬吸。
- 自检用面积覆盖率光栅化器把半像素渲染与吸附后渲染逐像素比对（吸附结果须与手工整数坐标逐字节一致），并输出边缘锐度：`hard_ratio` 为无抗锯齿毛边的硬边占比（半像素字形为 0，吸附后为正）；`mean_grad` 仅作参考——L1 梯度守恒，一条硬边摊成两条半强边时它不变。

错误码：`SNAP_OK` / `SNAP_E_PARAM` / `SNAP_E_CAP` / `SNAP_E_WIDTH`。
