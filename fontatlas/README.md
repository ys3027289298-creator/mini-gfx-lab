## Gamma 校正

深色背景上字形边缘发灰，是因为覆盖率在线性光下定义、渲染端却在
sRGB 空间直接 lerp，中间覆盖率被压暗。模块提供：

- `GammaConfig { gamma, enabled }` + `bitmap_gamma()`：按目标 gamma
  把覆盖率重映射为 `c^(1/gamma)`（默认 2.2）。`enabled = 0` 时位图
  逐字节不变，可随时切回原始曲线；开启时只改像素值，轮廓（非零掩码）
  与实心像素不变，字形形状不受影响。
- `blend_linear(fg, bg, cov, gamma)`：线性空间参考混合（解码→lerp→
  编码），即线性光照下手工校正的结果，用于校验。
- `blend_naive()`：渲染端现有的 sRGB 空间 lerp，重映射后的覆盖率
  直接喂给它即可逼近线性结果。

自检输出的数据（50% 覆盖率边缘像素）：

- 与线性参考的偏差：纯黑底 0；近黑底（bg=16）最大 12/255，未校正管线为 61/255。
- 对比度（WCAG 式比率）：暗底白字 5.76 → 10.97；亮底黑字 3.85 → 9.30。
