# fontatlas

字形货架装箱、字距调整，以及单字重字体的伪粗体 / 伪斜体合成。
`make test` 跑自检。

## 伪样式

真实字体常常只带一个正体字重。`glyph_apply_style` 在共享的
`GlyphBitmap`（8 位覆盖率 + 相对原点的 `origin_x/origin_y`）上合成缺失的样式：

| 样式 | 做法 |
|---|---|
| 粗体 | 对 4× 超采样的覆盖率掩码求有符号距离场，沿轮廓法线外推 `bold` 像素（`FT_Outline_Embolden` 的思路）。笔画在两个法线方向各宽 `bold`，斜线、圆弧、笔画端点一致。 |
| 斜体 | `x' = x + slant * (baseline - y)`。按行平移，用定点精确面积权重重采样到加宽的画布，`origin_x` 随平移一起更新。行不做缩放，笔画宽度与灰度覆盖不丢。 |
| 叠加 | 先粗体（各向同性加粗），再对加粗结果错切。 |

画布与原点都会跟着新外框走：粗体四周各留 `ceil(bold)+1` 像素（增长量 + 抗锯齿），
斜体画布恰好等于错切后的墨迹包围盒。因此两种样式都不裁剪自身，装入 atlas 时用
`glyph_apply_style` 产出的 `w/h` 即可。

半径 / 错切超出合理范围、或加 padding 后超过 `GLYPH_MAX` 时返回 `-1`；
`s` 为 0 时是原图逐字节拷贝。

## 自检的主要内容

- `bold_worst_width_error` / `bold_width_under_1px`：自检自带一个解析光栅器，
  用同一组笔画分别渲染 3.0px 与 3.0px+Δ 的"真实粗体"，在 16 条探针线上按
  0.5 覆盖率轮廓测笔画宽度。0.5 / 0.75 / 1.0 三种半径下最差偏差远小于 1 像素。
- `bold_pads_without_clipping`：粗体输出四周无墨迹、尺寸与原点正好是 pad 后的值。
- `italic_*`：每行墨量守恒、质心落在 `slant*(baseline-y)+origin` 上、逐像素抽检
  平移后的墨迹仍在（不丢边缘）、画布与原点与错切包围盒完全一致。
- `stack_*`：叠加后每行水平墨迹段宽度不变、错切几何正确、无裁剪。
- 另外用变异测试验证过：斜体不扩画布、粗体用固定阈值、padding 不足、错切时缩放、
  只做水平加粗这五种错误实现都会被上述自检判为失败。
