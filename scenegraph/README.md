# scenegraph

场景图遍历 + 可见性剔除 + 按 (材质, 深度) 合批，与逐物体直绘逐像素一致。

```bash
make test
```

## 两条路径

- **naive（直绘）**：DFS 遍历中每个可见物体立即设 `(material, depth)` 状态并绘制，状态与上一个物体不同即记一次切换。
- **batched（合批）**：同一次遍历只生成绘制项，再按状态合并为批次绘制；输出绘制项数与状态切换次数。

两条路径各自写入一块软件 framebuffer，测试用 `memcmp` 逐字节比对。

## 正确性依据

合批允许重排，但重排受一条偏序约束：**DFS 序中 y 在 x 之前、且两者屏幕矩形相交时，y 必须先于 x 绘制**。

- 新项 x 入批前，先 flush 所有与 x 矩形相交的异状态开放批 → 任何存在像素重叠的项严格保持直绘顺序；
- 不相交的项即使被重排，也只触及互不相交的像素集合，最终画面不变；
- 因此 batched 与 naive 的 framebuffer 逐字节相同（测试 `pixel_identical=1`）。

## 剔除

- `visible` 沿遍历栈继承，隐藏节点的整棵子树按 `sub_n` 一次性跳过；
- 局部 AABB 在 `scene_finalize` 中自底向上合并；遍历时世界包围盒与相机矩形不相交则整棵子树跳过。

## 线性开销

遍历使用显式栈迭代 DFS（无递归），每个节点恰好一次 push/pop。深度只增加栈高水位（O(depth) 内存），不增加工作量；深链基准（500/1000/2000 层）验证节点数翻倍时时间近似翻倍。
