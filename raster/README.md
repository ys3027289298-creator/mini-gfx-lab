# raster

软件三角形光栅化：视口变换、近平面裁剪、透视校正插值、背面剔除、深度测试。

```bash
make test
```

自检把逐像素结果和两条独立参考做对比：

- **解析参考**：直接对屏幕空间多边形的重心坐标求值，和边函数不是同一套代码
- **射线参考**：从眼点向像素中心发射射线，与*未裁剪*的三角形求交（Möller–Trumbore），
  只保留近平面之前的交点——这样近平面裁剪的正确性由“射线求交”独立判定

覆盖项：视口映射、逐像素覆盖/深度/属性一致、共享边无缝隙无重叠、填充规则唯一归属、
遮挡与绘制顺序无关、近平面裁剪不裂缝不重复、边界外不写、背面剔除。

一万三角形（640×360，100×50 四边形网格，含随机抖动）的填充耗时见
`fill_10k_ms_best` / `fill_10k_ms_median` / `fill_10k_mtris_per_s`。
