# sky

渐变天空球 + 可开关的解析太阳/光晕层 + 地平线硬遮罩。

- 太阳按方位角/仰角放置；仰角超出地平线范围 `[0, π/2]` 一律拒绝，配置不被修改
- 光晕强度由太阳仰角决定：贴地平线时暖而强，天顶时弱而偏白
- 遮罩层把地平线以下的采样整体替换为地面色，杜绝太阳光泄漏
- 关闭太阳层时渲染器退化为改动前的纯渐变球，逐字节一致（自测校验）
- 两条求值路径对照：`sky_analytic` 为逐像素解析公式，`sky_dome` 为渐变球
  顶点插值 + 逐像素太阳；自测按区域（地平线以下/地平线/高空/天顶/光晕/日盘）
  给出平均与最大通道误差
