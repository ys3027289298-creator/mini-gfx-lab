# envprobe

环境反射立方图。旧做法是一张固定方向的立方图：相机连同它的反射查询一起转到
背面时，查到的仍然是采集那个朝向的环境，转得越远错得越多。这里改成按当前视角
把六个方向分别采样一遍再拼成一张图；六张面各自独立渲染时会在共享边处错开半
个纹素，所以拼接阶段把接缝两侧的纹素取平均，让接缝逐位连续。

```bash
make test          # 自测
./envprobe         # 同上
./envprobe res=128 stitch=1
./envprobe faces=4 # 非法：报错并指出字段
```

## 接口

```c
int probe_render(const ProbeCfg* cfg, float* out, float* scratch,
                 char* err, size_t errlen);
```

`ProbeCfg{ faces, res, stitch }`：

| 字段 | 合法值 | 非法时 |
|---|---|---|
| `faces` | 必须是 6 | 返回 -1，出错信息含 `probe.faces=<值>` |
| `res` | `[2, 1024]` | 返回 -1，出错信息含 `probe.res=<值>` |
| `stitch` | 0 / 1 | 返回 -1，出错信息含 `probe.stitch=<值>` |

校验在任何渲染之前完成；非法配置不会消耗渲染工作。命令行入口把同一个信息打到
stderr，并以非零状态码退出；未知参数名同样报错。

输出为面优先、RGB 交错的浮点图：面 `f` 占 `[f*res*res, (f+1)*res*res)`，面序为
+X、-X、+Y、-Y、+Z、-Z，所有采样都在纹素中心。`stitch=0` 时 `out` 就是逐面渲染
的原始结果，和改动前的路径逐字节一致。

## 接缝处理

两个相邻面沿共享棱采到的是一组方向：每条棱外侧那一排纹素在两侧各自距棱半个纹素，
数值天然差一点。拼接只做两件事，且只碰最外一圈纹素：

1. **棱**：每条棱上（不含角点）的纹素与对侧最近的一个纹素取平均，两侧都从拼接前
   的原始面写入，所以一对纹素结果逐位相同。
2. **角**：立方体 8 个角各由三张面共享；每个角的三个纹素取三者平均，角上任意一对
   也逐位相同。

面的内部纹素完全不参与。拼接使用独立的原始渲染副本，不就地累积，因此结果与
处理顺序无关。

## 自测输出

| 指标 | 含义 | 本次数值（`res=64`） |
|---|---|---|
| `legacy_err_yaw0/90/180` | 固定立方图在 0°/90°/180° 视角下的平均通道误差 | 0 / 0.053 / 0.162 |
| `legacy_max_yaw180` | 转到背面时的最大通道误差 | 0.693 |
| `seam_drift_raw` | 拼接前，跨接缝纹素对的最大通道差 | 0.015831 |
| `seam_drift_stitched` | 拼接后同一度量 | 0（逐位相等） |
| `seam_scale` | 同一面上跨一个纹素的法向最大差值，作为接缝误差的量级参照 | 0.026362 |
| `face` 表 | 每面 `changed / max_abs_err / mean_abs_err`，对照该方向单独渲染的结果 | 每面 252 个纹素被改，最大 0.0079，平均约 1e-4 |

`changed` 恒等于 `4*res-4`（最外圈），即拼接只动边界；`interior_untouched`
逐纹素断言内部与单独渲染的结果相同。逐面误差就是拼接本身引入的差异：接缝处取
平均，离接缝一个纹素的面内像素不受影响。`seam_error_is_subtexel` 断言拼接前的
接缝误差不超过一个纹素的法向梯度——这是"两侧各差半个纹素"应有的量级，而不是
表错方向导致的大跳变。

`stitch_off_bit_identical` 用 `memcmp` 断言不启用拼接时输出与逐面渲染完全一致；
`stitch_on_differs` 确保拼接确实改变了画面（否则上面那些零值没有意义）。

`resolution_sweep_continuous` 在 `res = 2,3,…,8,16,…,128` 上逐一验证拼接后接缝
零漂移；命令行也可用 `res=` 直接跑任意合法分辨率（1 与 1025 都会被拒绝）。

## 邻接表怎么来的

`EDGES` 表记录了每面的四条边分别接哪张面、接的是对方的哪条边、共享边是否反向。
它由上面六个面基（`n/u/v`）的几何棱方向逐点匹配推导得出；自测用两条独立断言守住
它：`edge_partner_reciprocal` 从两侧走一遍必须回到原纹素，`edge_partner_direction_adjacent`
要求配对纹素的方向点积 ≥ 0.995（即确实隔着同一条棱），`corner_groups_three_faces`
要求八个角各恰好由三张面共享。表写错任何一格，这些断言会先于图像比对失败。
