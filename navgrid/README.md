## 反向批量寻路

多个单位去往同一目标时，逐单位 A* 的总耗时随单位数线性增长。
本实现把搜索拆成两层：

1. `reverse_field`：从目标做一次反向 Dijkstra（移动图边对称，
   正向从目标出发即等价于反向），得到全格到目标的精确最短距离场。
   搜索代价只付一次，与单位数无关。
2. `gradient_path`：每个起点沿距离场严格下降的合法邻居回溯，
   每步距离差必须恰好等于实际步长（直走 1 / 对角 √2），tie-break
   取离目标欧氏距离最近的格子保证确定性；严格下降使环路不可能出现。
3. `path_valid` 对每条回溯路径逐点校验：起终点正确、每格可行走、
   每步满足 `step_ok`（含禁止切角）、距离场严格下降且差值等于步长。

基准（40×24 网格、约 18% 障碍、100 个随机可达起点，20 轮计时）：

- 批量总耗时在 1→100 单位时仅增长约 1.3×（距离场一次构建、全程共享），
  逐单位 A* 增长约 125×；
- 交叉点约在 25~30 个单位，100 个单位时批量方案快约 4~5 倍；
- 100 条梯度路径全部通过逐点合法性校验，且路径长度与逐单位 A*
  逐条对比零偏差（距离场给出的就是最短距离）。
- 障碍格起点与封闭区域内不可达起点均返回 `-1`。
