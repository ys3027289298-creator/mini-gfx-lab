# mini-navgrid

8 方向 A*、对角禁止切角、视线可达平滑、增量重规划实验平台。

```bash
make test
```

## 路径导出与自校验（`src/navpath.c`）

A* 只输出路径点，外部工具无法独立核对。本模块把一次寻路结果写成带版本号的
文本文档，并在读入后按同一代价函数复算、逐项比对。

### 代价函数

A* 扩展与导出/校验共用 `nav_cost(dx, dy)`：

| 步长 | 代价 |
|---|---|
| 正交 1 格 | `1.0` |
| 对角 1 格 | `sqrt(2)` |
| 平滑后的任意段 | 两点欧氏距离 |

改代价只需改这一处，A* 与导出结果不会漂移。

### 文档格式

```
NAVPATH version=3 w=10 h=5 start=0,0 goal=8,4 n=12 expanded=18 total=11.414214
points 0,0 1,0 2,0 3,0 4,1 4,2 5,2 6,2 7,2 7,3 7,4 8,4
costs 1.000000 1.000000 1.000000 1.414214 1.000000 1.000000 1.000000 1.000000 1.000000 1.000000 1.000000
end
```

* 首行是 `key=value`；未知 key、重复 key、本版本不该出现的 key 一律报错。
* `costs` 有 `n-1` 个值，对应 `pts[i-1] -> pts[i]`；首点的代价恒为 0。
* `expanded` 是本次 A* 闭合的节点数，导出只读取、从不重算。
* `end` 之后只允许空行。

版本与迁移链：

| 版本 | 内容 | 读入后的迁移 |
|---|---|---|
| 1 | 只有 `w/h/start/goal/n` 和 `(x,y)` 点列 | 用 `nav_cost` 补算逐段代价与 `total`；`expanded` 标记为未知（`-1`） |
| 2 | 增加 `expanded`、`total`、`costs` | 无数据变更 |
| 3 | 增加可选 `codec=rle` 压缩；`expanded` 可省略 | 当前版本 |

另外兼容旧的裸点列（只有 `(x,y) (x,y) ...`）：调用方需提供 `w/h`，按 v1 迁移。

### 压缩

`codec=rle` 时 `points` 改为相对上一点的单位步编码（`1`..`8` 对应
`DIRS[]` 顺序，非单位步仍写 `dx,dy`），并与 `costs` 一起做 `N*值` 形式的
游程编码。`compress=1` 仅在更小时选用，`compress=2` 强制。

### 校验

`navpath_verify()` 用 `nav_cost` 复算每一段，与导出值按 `1e-6` 容差比对，
并在第一个不一致处停下，报告段号与两个数值。同时检查：

* 端点与 `start`/`goal` 一致，所有坐标在网格内；
* `total` 与逐段之和一致；
* `expanded` 与调用方期望值一致（`-1` 表示跳过）。

### 自检

`make test` 会覆盖 v1/v2/v3 × 三种压缩模式的往返、旧文件迁移、
逐段篡改（第 1 段与第 4 段）、字段缺失、坐标越界、未知版本、截断、
RLE 越界、网格尺寸不符，并打印体积对比。当前样例（raw 12 点）：

```
bytes plain=243 compressed=157 legacy=134 ratio=1.55
```

`smooth` 路径因点少、段长，RLE 收益有限；压缩对比数字随路径形状变化。
