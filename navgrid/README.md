# mini-navgrid

8 方向 A*、对角禁止切角、视线可达平滑、增量重规划实验平台。
附带巡逻路线模块：路点循环、每点可配停留帧数、击退后回到最近路点续巡。

```bash
make test
```

## 巡逻路线

| 需求 | 做法 |
|---|---|
| 路点循环 | `Route` 存路点与每点停留；`patrol_begin_leg` 走 `(cur+1) % n` |
| 每点停留可配 | `dwell[i]` 单位是帧，整数倒计时 |
| 停留精确到帧 | `dwell=N` 静止 N 帧，第 N+1 帧起步；移动帧数 = 格数 × `cell_frames` |
| 十圈不漂移 | 位置每帧由整数格点端点 + 整数帧计数重新插值，到达路点精确吸附 |
| 被击退能续巡 | `patrol_knockback` → BFS 按可走距离选最近路点 → 沿缓存路径返回 |
| 改路线不重新寻路 | 路径按起终点格缓存；`patrol_set_route` 只让受影响的腿失效，新腿在用到时才规划 |

关键点：

- 所有时间都是整数 tick（1 tick = 1 帧），不存在浮点累积。
- 击退返回不会误计一圈：只有从 wp0 正常出发、再正常回到 wp0 才 `laps++`。
- 目标路点在新路线里仍存在且仍在巡逻中时，当前腿直接保留（路径缓存命中）。
- 路点不可达时 `patrol_begin_leg` 把状态置为 `PATROL_STOPPED`，不会卡在空转。

自测覆盖：帧精度停留、一/十圈路径规划次数、第 10 圈与第 2 圈逐帧坐标完全相等、
击退后补规划次数有界、改路线只补规划 2 条新腿、绕墙时最近路点按可走距离判定。
