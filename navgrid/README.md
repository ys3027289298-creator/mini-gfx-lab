# mini-navgrid

8 方向 A*、对角禁止切角、视线可达平滑，以及带权地形上的最优性验证。

地形代价：进入格子 q 的一步代价 = 步长 × q 的权重（权重为整数 ≥ 1）。
代价用整数定点表示（正交 1000、对角 1414 毫步，即 floor(1000·√2)），
因此 A* 与 Dijkstra 的结果可以精确相等比较，不受浮点累加顺序影响。

启发式为闭式八方向距离（octile），只按最小权重 1 估计、忽略障碍：
可采纳且一致；不使用距离表、landmark 或任何缓存。

`make test` 会验证：

- 启发式在全部可达格上可采纳、在全部合法有向边上一致（逐格穷举）
- 四组权重图（1、1–2、1–4、1–9）上 A* 与 Dijkstra 的最优代价逐条查询严格相等（差值 = 0）
- 反向 Dijkstra 距离场与 A* 路径代价交叉校验一致
- 每组图上 A* 的扩展节点数都少于无启发式的 Dijkstra
- 317×317（100,489 格）搜索 A* 单次低于 100 ms

make test
