# mini-navgrid

8 方向 A*、对角禁止切角、视线可达平滑，以及分层路径搜索（HPA*）实验平台。

```bash
make test
```

## 两套规划器

共用同一个二叉堆 A* 内核（`astar_rect`，可把搜索限制在任意矩形区域内）：

- **全量 A*（基准）**：在整张图上搜索，输出逐格路径，再做 LOS 平滑。
- **分层 HPA***：`hpa_build` 离线构建粗粒度抽象图，`hpa_query` 在线查询。

### 粗粒度网格与连接点的构建（`hpa_build`）

1. **分区**：把地图按边长 `cs` 切成规则矩形簇（三档：16/32/64，对应
   512×512 地图上的 1024/256/64 个分区）。
2. **连接点（入口）**：扫描相邻簇的每条边界，找出两侧都可行走的最大连续
   格子段（entrance run）；每段在两端各放一个抽象节点，跨边界用权值 1 的
   转移边相连。只取两端是因为同一段内的格子在簇内彼此可达，中间节点不会
   产生更优路径。
3. **簇内边**：对每个入口跑一次**单源多目标 Dijkstra**（`astar_multi`），
   一次受限搜索即得到它到本簇所有其他入口的精确最短距离，把传统 HPA* 的
   O(k²) 次两两 A* 降为 O(k) 次。
4. **查询**：起终点作为两个虚拟节点，用局部 A* 连到所在簇的各入口；在
   抽象图上跑 A* 得到跨簇入口链；再对链上每条边用矩形受限的局部 A* 细化
   成逐格路径，最后复用同一套 LOS 平滑。

### 正确性保障

- **不穿墙**：细化后的原始路径逐格用 `step_ok` 校验（对角步要求两个正交
  邻格都开放）；平滑后的航点链用 supercover 视线算法 `line_of_sight` 校验。
  LOS 采用整数 Bresenham DDA 遍历线段穿过的每个格子，对角穿越时执行与
  `step_ok` 完全相同的切角规则，单元测试验证 LOS 不会放行任何 `step_ok`
  拒绝的走法。两种校验在基准输出中分别报告（`clip raw=` / `smooth=`）。
- **长度偏差**：平滑后路径相对全量 A* 基准的长度差，逐查询统计平均值与
  最大值，验收线为最大偏差 ≤ 5%。
- **可达性一致**：HPA* 与基准对每组起终点的可达性必须一致。

### 基准结果（512×512，20 组固定随机查询，gcc -O2）

随机障碍图（障碍率 0.25）与房间走廊图各一张，三档分区数的构建耗时、
查询耗时（相对基准的加速比）、抽象/局部搜索扩展节点数、长度偏差、穿墙
计数全部由 `make test` 打印。典型结论：

- 房间走廊图上 cs=16 查询加速约 4×，随机图上约 2×；簇越小抽象层越省、
  局部细化越便宜，簇越大则反之，cs=64 的查询可能慢于全量 A*——三档数据
  用于展示这一权衡。
- 抽象图只构建一次、可跨查询复用；构建耗时单独列出，不计入查询耗时。
- 所有档位平滑路径长度偏差均 < 3%，穿墙计数为 0。
