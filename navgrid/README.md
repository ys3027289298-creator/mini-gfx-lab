# mini-navgrid

8 方向 A*、对角禁止切角、视线可达平滑、增量重规划实验平台。
附带拦截预测演示：按目标速度外推、迭代修正拦截点、追不上时回退到跟踪。

```bash
make test
```

拦截预测要点：

- **外推**：目标速度恒定假设下按时间步进到预测点（撞墙按轴反弹），取最近可走格。
- **迭代修正**：`t <- 到预测点的路径耗时`，最多 `MAX_INTERCEPT_ITERS=8` 次；`|eta-t| < 0.1s` 视为收敛。
- **分辨率下限**：网格比容差粗时迭代会在相邻两格间二周期振荡，检测到重复瞄准格即停止并取误差最小的一格（结果只取决于目标状态，因此可复现、不漂移）。
- **回退**：目标速度 ≥ 追击者且正在远离时直接判定无解；其余失败经迟滞（连续 2 次失败才降级，冷却 0.15s 后 1 次成功恢复）切回跟踪。单次失败保留上一个瞄准点，不调头，避免路径抖动。
- **数据**：`make test` 会打印追及率（追击 / 预测 / 理想拦截）、平均命中时间、迭代次数上界、回退比例、回退期掉头次数，以及“抖动目标”“逃跑目标”两组对照。
