## 视线预计算矩阵压缩

`VisMat` 把全图格子两两可见性预计算后压缩存储：

- **对称性**：`line_of_sight` 先做方向规范化（始终从小编号端采样），保证
  `LOS(a,b) == LOS(b,a)`，因此只存上三角（`i < j` 的配对）。
- **按行位压缩**：每对 1 bit，行 `i` 的 bit 偏移为 `i*(2n-i-1)/2`，总计
  `n(n-1)/2` bit ≈ 全字节矩阵的 1/16（含索引数组也优于 1/8）。
- **按需解压查询**：单点查询是一次无分支位测试（`vm_visible_id`，min/max 用
  cmov 避免随机配对的交换分支误预测）；`vm_row_bytes` 可把整行解压成字节数组
  供批量扫描；`vm_visible_batch` 提供批量点查。

`make test` 内置三项验收（64×64 随机障碍图，约 3200 个可走格）：

1. 内存 ≤ 全矩阵的 1/8（实测约 1/15；十万格投影 10 GB → 626 MB，约 1/16）。
2. 一百万组随机配对 + 整行解压结果与直接 `line_of_sight` 遍历完全一致。
3. 两千万次批量查询吞吐相对全字节矩阵下降不超过 20%（实测压缩版因缓存
   友好常常更快）。
