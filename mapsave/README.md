# mapsave

地图存档的压缩序列化：行程编码（RLE）、版本号、校验和，损坏文件拒绝并报偏移。

`make test` 跑自检，输出压缩率与损坏检测结果。

## 格式

小端序：

| 偏移 | 大小 | 字段 |
|---|---|---|
| 0 | 4 | 魔数 `MGMS` |
| 4 | 1 | 主版本（结构变更时递增，读者拒绝更高主版本） |
| 5 | 1 | 次版本（只做附加变更，旧读者接受） |
| 6 | 1 | 标志位（保留，未知位忽略） |
| 7 | 1 | 每格位宽：8 或 16 |
| 8 | 2 | 层数 |
| 10 | 2 | 宽 |
| 12 | 2 | 高 |
| 14 | 2 | 保留 |
| 16 | 4 | 头部校验和（FNV-1a over 0..15） |
| 20 | ... | 每层：u32 层校验和 + 行程数据 |
| n-4 | 4 | 文件校验和（FNV-1a over 0..n-5） |

行程记录（重复直到产出 宽×高 个格子）：

- `0x00` 字面量：u16 数量 + 原始格子
- `0x01..0xFE` 重复：标签即数量 + 一个格子值
- `0xFF` 扩展重复：u16 数量 + 一个格子值

空格与实心区域各占几个字节；随机数据只多出零头的帧开销。

## 兼容与校验

- 版本：主版本不符直接拒绝；次版本更新但主版本相同则接受。
- 三层校验：头部（元数据损坏）、每层（解码结果损坏）、整文件。
- 任何校验失败都返回 `NULL` 并给出首个可疑字节的偏移，不会返回半张图。
- 读取时先校验尺寸上限再分配，避免损坏的长度字段导致巨量分配。
