# transsort

半透明水面叠在不透明船身上的描边问题：按深度排序后再混合，并保证渲染状态
切换不会打乱深度顺序。

软件帧缓冲（OVER / ADDITIVE 混合、1px 抗锯齿边缘）复现亮边，四条管线对照：

| 管线 | 做法 |
|---|---|
| `naive-submission` | 按提交顺序直接画，不排序 |
| `depth-only-key` | 只有深度的退化排序键，等深用任意决胜（模拟不稳定排序） |
| `state-bucket` | 按渲染状态分桶合批，跨状态重排以减少状态切换 |
| `fixed-composite` | 复合键 `(深度, 不透明优先, 稳定 seq)` + 稳定排序，状态只按序应用、不重排 |

两个缺陷必须一起修，只做排序键仍会出亮边：

1. **排序键退化**：深度相同的物体（如入水的船艏与水面）在深度-only 键下无法
   定序，不稳定排序会把半透明水面提到不透明船身前；
2. **状态切换插入**：按 blend/纹理/程序分桶的合批器会为了少切一次状态，把
   物体移出它的深度位置。OVER 半透明与不透明船身的交叉不可交换，顺序一错
   就在轮廓抗锯齿像素上产生亮边（加法与不透明在覆盖区可交换，不会出错）。

每组场景打印三个物体的实际绘制顺序、状态切换点 `[switch -> ...]`、船身边缘
像素上相对逐像素参考图的亮度偏差，并在仍有亮边时指出根因是排序键退化还是
状态切换插入。

三种叠放关系各渲染一次：

- 场景 A：水面全在船身前
- 场景 B：船艏部分入水（船艏与水面等深）
- 场景 C：水面全在船身后
