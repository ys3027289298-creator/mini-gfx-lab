# blockpack

图标图集（RGBA8 原始像素）的 4×4 块压缩打包，`make test` 跑自检。

## 格式

| 标签 | 块格式 | 大小 |
|---|---|---|
| `BC1` | 两个 RGB565 端点 + 16 个 2 位索引（DXT1/BC1 风格四色调色板，alpha 视为不透明） | 8 B + 1 B 标签 |
| `RAW` | 原始 16 个 RGBA8 纹素，无损 | 64 B + 1 B 标签 |

- **按质量阈值选格式**：逐块计算相对原始纹素的 MSE，不超过调用方阈值才用 BC1，否则回退 RAW；阈值传 0 时整图无损（`psnr=inf`）。`bp_mse_from_psnr()` 可从目标 PSNR 反算阈值。
- **边界块补齐**：超出图集边缘的纹素按最近边缘钳位复制，不引入外来颜色；补齐纹素只参与端点拟合，不计入误差也不写回，因此不会产生可见接缝。非 4 倍数尺寸（如 18×13、1×1）均有自检。
- **不越界**：所有读写都走带容量检查的游标（`PackBuf`/`ReadBuf`），缓冲区不足返回 -1 并置溢出标志；截断流、坏魔数、未知标签、目标缓冲不足同样拒绝。`make asan` 用 ASan+UBSan 复核。
- **数据输出**：自检对渐变图、噪声图、透明图、边界图分别打印块数（bc1/raw）、原始与打包体积、压缩率、bpp，以及 maxdiff / MAE / MSE / PSNR 色差指标。

文件流布局：4 B 魔数 `ATLP` + 宽高与网格（u16×4）+ 总长度（u32，共 16 B 头），之后按网格顺序逐块存放标签与负载。
