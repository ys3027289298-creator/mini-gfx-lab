# terrain

地形分块 + 屏幕误差 LOD：每块按四叉树层级预算几何误差，按视锥剔除、按像素误差选级，
块边界用邻居细分缝合，无裂缝、无裙边。

- 几何误差：按该级实际画出的两三角形逐采样点测高差，故误差包含对角线，可作为上界。
- 选级：`err * 焦距 / 距离 ≤ 1px`（保守取最近点距离）。
- 平衡：只对已绘制的邻居做 ±1 级约束，避免相邻块级差过大。
- 缝合：与更细邻居共享的边上，粗侧把每条边单元中点切一刀并从单元中心扇形三角化，
  两侧顶点列表逐点相同。

```bash
make test
```

自测输出块数、绘制三角形数、绘制耗时（LOD vs 全精度）、天际线最大像素差与裂缝像素数。
