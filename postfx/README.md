# postfx

后处理链与渲染目标缓冲池。`make test` 跑自检。

- 图（pass / resource）编译期校验：输入输出尺寸规则、重复生产者、环检测
- Kahn 拓扑排序按依赖定执行顺序（同条件按 pass 下标打破平局，结果确定）
- 每个中间资源按"最后一个消费者"算生命周期，死亡点归还按尺寸分桶的缓冲池
- 缓冲池有硬上限，超限返回 `PF_ERR_CAP`；朴素调度器每步新开缓冲、帧末才回收，作为对照
- 两种调度共用同一套像素 kernel，对每个产出资源做 host 回读并 `memcmp`，逐像素（逐 bit）一致
- 自检打印线性链与 bloom DAG 在链变长时的分配次数、峰值缓冲数、峰值显存
