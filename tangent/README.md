# tangent

法线贴图切线基构造：主参考向量退化时切换备用参考，消除角色转身时的闪白。

- 切线 `T = normalize(R - N*(N·R))`，当法线 N 扫过主参考 R1 附近时投影长度趋零，归一化结果由浮点舍入决定，着色法线瞬间偏转 → 闪白。
- 修复：`|N·R1|` 超过门限时切换到备用参考 R2（R1⊥R2）。
- 门限由夹角推导，非经验值：R1⊥R2 时 `|N·R1|² + |N·R2|² ≤ 1`，故 `min(|N·R1|,|N·R2|) ≤ √2/2`，最坏情形在 45° 取等。取 `cos45° = √2/2` 可保证 `|N×R| ≥ √2/2`，且对双正交参考是极小极大最优。

## 自测

`make test` 让角色绕垂直轴转一整圈，每 15° 一帧共 24 帧，逐帧记录着色法线相对双精度基准的偏离度：

1. `buggy`：无切换的原实现 —— 法线扫过 R1 的帧偏离爆表（闪白复现）。
2. `fixed`：按门限切换 —— 全程无超门限帧。
3. `self-check`：故意把备用参考选成与主参考共线 —— 超门限帧数 > 1 时诊断触发，列出两个参考向量的夹角。
