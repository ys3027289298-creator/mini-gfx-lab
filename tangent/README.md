# mini-tangent

按位置与 UV 重建每顶点切线，修复法线贴图墙面斜角发黑、切线方向混乱的问题。

- 每三角形按 Lengyel 分子形式累加切线/副切线（面积加权，保留翻转 UV 的符号）
- 每顶点对几何法线做 Gram-Schmidt 正交化，切线存三通道单位向量，手性 w 另存 `sign[]`，着色端 `B = cross(N, T) * w`
- UV 退化（零 UV 面积）的三角面标记 `degen_face[]`；累积极值为零的顶点退回屏幕空间近似（取屏幕右方向在切平面上的投影，边缘观察时退回屏幕上方向）
- UV 完全重合（严格浮点相等）的处理：先按面邻接与同位置拆点做并查集合并，镜像 UV 接缝属于同一连通分量会放行；不相连的两块面被钉到同一 UV 时直接报错，stderr 列出同组顶点索引
- 离线软光栅把重建 TBN 的着色结果与手算法线逐采样比对，按面输出 `shade_mean/max`、法线夹角与接缝标记，并在斜角区域统计发黑情况；另含乱序切线对照实验复现故障
